# 定时唤醒工具联调与SSH超时定位（2026-11-26）

## 结论

用户截图中的 `timed out` 发生在连接网关阶段，尚未开始任何唤醒测试。
实测 `192.168.100.78:22` TCP连接超时，`192.168.100.81:22` 可连接并返回OpenSSH_9.6。
该错误与定时唤醒组合指令、ID222～255或串口无关。

在线网关.81上的小规模联测通过：模式3、ID222和223均第一次获得有效无线判定响应。
另做不发送RF的对照，终端连续3次定时恢复，工具均判WAKE_TIMEOUT，没有把定时唤醒误判PASS。
本次未遍历其余ID224～255。
