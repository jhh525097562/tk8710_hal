# 射频直流校准方案

## 1. 文档目的

本文用于指导单个射频模块配合 TK8710 芯片进行射频发射直流校准。校准目标是在固定发射 Tone 条件下，通过 JSPI 写入 TK8710 直流补偿寄存器，观察频谱仪中心频率处的直流分量变化，逐步调整 I/Q 两路直流补偿值，直到中心频率直流分量满足要求，并将最终补偿值通过 I2C 写入射频 Flash 保存。

## 2. 校准环境

### 2.1 硬件环境

| 设备 | 用途 |
|------|------|
| 射频测试板 | 单个射频模块 + TK8710 芯片，用于执行发射 Tone 和直流补偿测试 |
| JSPI 工具 | 连接 TK8710，用于初始化 8710、配置发射 Tone、读写寄存器 |
| 频谱仪 | 测量中心频率处的直流分量大小 |
| I2C 接口 | 连接射频模块，用于将最终直流补偿值写入射频 Flash |

### 2.2 软件环境

| 软件/接口 | 要求 |
|-----------|------|
| `Test8710RFTxTone.exe` | 支持初始化 TK8710 并输出指定频点和增益的发射 Tone |
| JSPI 驱动 | 支持配置 TK8710，支持全局寄存器读写 |
| I2C 写 Flash 工具或接口 | 支持将最终 I/Q 直流补偿值写入射频 Flash 并可回读确认 |

## 3. 频谱仪设置

频谱仪用于读取发射中心频率处的直流分量。校准过程中频谱仪设置保持不变：

| 参数 | 设置 |
|------|------|
| Center Frequency | 与 `Test8710RFTxTone.exe` 配置的发射频点一致，本方案示例为 `509100000 Hz` |
| Span | `200 kHz` |
| RBW | `1 kHz` |
| VBW | `1 kHz` |
| Trace Mode | `Average` |
| AVG Count | `10` |
| 读数位置 | 中心频率处的直流分量 |

每次写入新的直流补偿寄存器值后，等待 `500 ms`，再读取并记录频谱仪中心频率处的直流分量。

## 4. 直流补偿寄存器格式

校准时写入直流补偿寄存器的值为 `32 bit`：

```text
bit[31:16] = I 路直流补偿值
bit[15:0]  = Q 路直流补偿值
```

I/Q 两路均按 `16 bit` 有符号补偿值处理，最高位为符号位。大部分射频直流偏移为正向偏移，因此初始校准方向优先按正向补偿递增。

寄存器写入格式如下：

```text
寄存器值 = ((I_DC & 0xFFFF) << 16) | (Q_DC & 0xFFFF)
```

示例：

```text
I_DC = 0x0400
Q_DC = 0x0000
写入值 = 0x04000000
```

在 `Test8710RFTxTone.exe` 中输入写寄存器命令时，地址和值用空格分隔：

```text
0x08c8 0x04000000
```

其中 `0x08c8` 为本次校准使用的直流补偿寄存器地址，`0x04000000` 为 I/Q 拼接后的 `32 bit` 补偿值。

## 5. 校准启动流程

1. 连接射频测试板、JSPI 工具、频谱仪和 I2C 接口。
2. 频谱仪中心频率设置为 `509.1 MHz`，并按第 3 章设置 Span、RBW、VBW、Trace 和平均次数。
3. 在测试程序目录运行：

   ```powershell
   .\Test8710RFTxTone.exe 6 509100000 42
   ```

   参数含义：

   | 参数 | 含义 |
   |------|------|
   | `6` | 测试速率/时隙模式 |
   | `509100000` | 发射 Tone 频点，单位 Hz |
   | `42` | 发射增益，十进制 `42`，对应 `0x2A` |

4. 等待 TK8710 初始化完成，建议等待 `5 s`，确认程序进入命令行交互状态。
5. 输入 `w` 并回车，进入写寄存器流程。
6. 先写入全 0 直流补偿值：

   ```text
   0x08c8 0x00000000
   ```

7. 写入后等待 `500 ms`，读取频谱仪中心频率处的直流分量，作为初始直流分量记录。

## 6. I/Q 迭代校准方法

### 6.1 基本原则

校准采用 I/Q 交替调整方式：

- 先调 I 路，再调 Q 路。
- 每次只调整一路，另一路保持上一次最优值不变。
- 每次写入后等待 `500 ms`，读取频谱仪中心频率直流分量。
- 若直流分量变小，说明当前调整方向有效，继续沿该方向调整。
- 若直流分量变大，回退到上一次较优值，并切换到另一路或减小步进。
- 当调整无明显改善时，降低步进并在 I/Q 两路之间反复微调。

### 6.2 I 路粗调

1. 保持 `Q_DC = 0x0000`。
2. 从 `I_DC = 0x0000` 开始，按 `0x0200` 步进正向增加：

   ```text
   I_DC = 0x0200, Q_DC = 0x0000 -> 写入 0x02000000
   I_DC = 0x0400, Q_DC = 0x0000 -> 写入 0x04000000
   I_DC = 0x0600, Q_DC = 0x0000 -> 写入 0x06000000
   ```

3. 每次写入后等待 `500 ms`，读取并记录直流分量。
4. 如果直流分量继续变小，则继续按 `0x0200` 增加 I 路。
5. 如果直流分量变大，则回退到上一次直流分量更小的 I 路值，并开始调 Q 路。

### 6.3 Q 路粗调

1. 保持 I 路为当前最优值。
2. 从当前 Q 路值开始，按 `0x0200` 步进正向增加：

   ```text
   I_DC = I_best, Q_DC = 0x0200 -> 写入 ((I_best << 16) | 0x0200)
   I_DC = I_best, Q_DC = 0x0400 -> 写入 ((I_best << 16) | 0x0400)
   I_DC = I_best, Q_DC = 0x0600 -> 写入 ((I_best << 16) | 0x0600)
   ```

3. 每次写入后等待 `500 ms`，读取并记录直流分量。
4. 如果直流分量继续变小，则继续按 `0x0200` 增加 Q 路。
5. 如果直流分量变大，则回退到上一次直流分量更小的 Q 路值，并切回 I 路。

### 6.4 I/Q 细调

完成 I/Q 粗调后，继续进行细调：

1. 将 I 路步进从 `0x0200` 降到 `0x0100`。
2. 保持 Q 路为当前最优值，继续沿直流分量降低的方向调整 I 路。
3. 如果 I 路调整无明显变化或开始变差，则回退到 I 路最优值。
4. 切换到 Q 路，使用同样的 `0x0100` 步进继续调整。
5. I/Q 两路反复切换，直到直流分量不再明显下降，或已经满足退出条件。

如需进一步压低直流分量，可在 `0x0100` 后继续降低步进，例如 `0x0080` 或 `0x0040`，但现场记录中需要标明实际使用的步进。

## 7. 退出条件和结果保存

满足以下条件时可以退出校准：

1. 频谱仪中心频率处的直流分量小于 `25 dB`。
2. 当前 I/Q 值继续调整后无明显改善，且回退后仍满足小于 `25 dB` 的要求。
3. 已记录最终寄存器地址、I 路值、Q 路值、32 bit 写入值和最终频谱仪读数。

校准结束后，通过 I2C 将最终 I/Q 直流补偿值写入射频 Flash。写入内容至少需要包含：

| 字段 | 说明 |
|------|------|
| `I_DC` | 最终 I 路 `16 bit` 直流补偿值 |
| `Q_DC` | 最终 Q 路 `16 bit` 直流补偿值 |
| `DC_WORD` | 最终写入 TK8710 的 `32 bit` 拼接值 |
| 校准频点 | 本次校准使用的发射频点，例如 `509100000 Hz` |
| 发射增益 | 本次校准使用的发射增益，例如 `42` |

Flash 的具体地址、字段顺序和校验方式以射频模块当前 I2C/Flash 协议为准。写入完成后必须执行一次回读，确认 Flash 中保存的 I/Q 值与本次最终校准值一致。

## 9. 复测要求

Flash 写入并回读一致后，需要重新初始化射频并复测：

1. 退出 `Test8710RFTxTone.exe`。
2. 重新启动测试程序：

   ```powershell
   .\Test8710RFTxTone.exe 6 509100000 42
   ```

3. 确认软件从射频 Flash 或射频配置流程中加载最终 I/Q 直流补偿值。
4. 频谱仪保持相同设置，读取中心频率处的直流分量。
5. 若复测直流分量仍小于 `25 dB`，且 Flash 回读值与最终校准值一致，则本次射频直流校准通过。

如果复测结果不满足要求，需要重新进入第 6 章 I/Q 迭代校准流程，并确认 Flash 写入值、软件加载值和 TK8710 实际寄存器值三者一致。

## 10. Windows TCP远程寄存器校准

### 10.1 启动TCP服务

Windows版本的 `Test8710RFTxTone.exe` 支持TCP寄存器服务模式。程序完成JTOOL、TK8710、RF和发射Tone初始化后，在主线程中串行处理TCP命令，避免控制台和网络线程同时访问JSPI。

使用默认地址 `127.0.0.1:12879` 启动：

```powershell
.\Test8710RFTxTone.exe 6 509100000 42 --tcp
```

指定监听IP和端口：

```powershell
.\Test8710RFTxTone.exe 6 509100000 42 --tcp --bind 192.168.1.100 --port 12879
```

参数说明：

| 参数 | 说明 |
|------|------|
| `--tcp` | 启用TCP服务模式；启用后不进入本地控制台命令循环 |
| `--bind` | 监听IPv4地址，默认 `127.0.0.1` |
| `--port` | 监听TCP端口，默认 `12879`，有效范围 `1~65535` |

`127.0.0.1` 只能由同一台Windows电脑上的校准程序访问。如果需要从另一台电脑访问，应绑定运行校准程序电脑的网卡IP，并在Windows防火墙中放行对应TCP端口。不要在非隔离网络中直接绑定 `0.0.0.0`。

### 10.2 TCP命令协议

协议使用UTF-8/ASCII文本，每条命令必须以换行符结尾。地址和值支持十进制或 `0x` 前缀十六进制。

| 命令 | 示例 | 成功响应 |
|------|------|----------|
| 连通检查 | `PING` | `OK PONG` |
| 读取寄存器 | `READ 0x08C8` | `OK READ 0x08C8 0x04000000` |
| 写入并回读 | `WRITE 0x08C8 0x04000000` | `OK WRITE 0x08C8 0x04000000 READBACK 0x04000000` |
| 断开当前客户端 | `QUIT` | `OK BYE` |
| 停止TCP服务并退出程序 | `SHUTDOWN` | `OK SHUTDOWN` |

`WRITE` 成功后服务端会立即回读同一寄存器。回读不一致时返回：

```text
ERR READBACK_MISMATCH 0x04000000 0x实际回读值
```

常见错误响应包括：

```text
ERR INVALID_COMMAND
ERR INVALID_ADDRESS
ERR INVALID_VALUE
ERR READ_FAILED 错误码
ERR WRITE_FAILED 错误码
ERR READBACK_FAILED 错误码
```

服务端写入和回读完成后立即响应。校准程序应在收到 `OK WRITE` 后等待 `500 ms`，再读取频谱仪中心频率直流分量。

### 10.3 PowerShell人工连通测试

```powershell
$client = [System.Net.Sockets.TcpClient]::new("127.0.0.1", 12879)
$stream = $client.GetStream()
$reader = [System.IO.StreamReader]::new($stream)
$writer = [System.IO.StreamWriter]::new($stream)
$writer.AutoFlush = $true

$reader.ReadLine()                 # OK RF_CAL_SERVER 1
$writer.WriteLine("PING")
$reader.ReadLine()                 # OK PONG
$writer.WriteLine("WRITE 0x08C8 0x04000000")
$reader.ReadLine()                 # OK WRITE ... READBACK ...
$writer.WriteLine("READ 0x08C8")
$reader.ReadLine()                 # OK READ 0x08C8 0x04000000
$writer.WriteLine("QUIT")
$reader.ReadLine()                 # OK BYE
$client.Close()
```

### 10.4 软件自动化测试

无需连接JTOOL或TK8710即可运行协议解析和本机TCP收发测试：

```powershell
mingw32-make -f cmake/Makefile.jtool rf_cal_tcp_tests
```

测试覆盖默认IP/端口、`PING`、寄存器读写、写后回读、非法地址/数值、回读不一致以及本机TCP连接和关闭流程。

### 10.5 Python图形化测试页面

为了避免反复输入PowerShell命令，仓库提供了仅依赖Python标准库的Tkinter测试页面：

```powershell
python tools\rf_calibration_gui.py
```

页面默认连接`127.0.0.1:12879`，提供以下功能：

- 一键启动`build_jtool\Test8710RFTxTone.exe`并自动等待TCP服务、完成连接；
- 连接、断开和`PING`连通检查；
- 输入寄存器地址后读取，或输入32位数值后写入并自动检查回读；
- 分别输入`I_DC`和`Q_DC`，自动按`I_DC[31:16] + Q_DC[15:0]`生成32位寄存器值；
- 直接执行“生成并写入”，以及在日志窗口查看每一步结果；
- 发送`SHUTDOWN`停止TCP服务。

I/Q输入既支持有符号十进制（例如`-12`），也支持16位原始十六进制（例如`0xFFF4`）。页面中的“本机服务”参数默认与本文示例一致：模式`6`、频率`509100000 Hz`、增益`42`。如果服务已经由命令行启动，只需使用页面上方的“连接”按钮，不需要再次启动。

页面通信和I/Q组字逻辑可在无JTOOL、无TK8710的环境中自动测试：

```powershell
python -m unittest discover -s test\tools -p "test_*.py" -v
```

自动化测试使用临时本机TCP模拟服务，不会访问实际寄存器。实际硬件验收仍需确认页面写入后的回读值一致，并按第6章流程观察频谱仪直流分量是否达到要求。
