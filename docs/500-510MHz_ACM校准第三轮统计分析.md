# 500–510 MHz ACM 初始化校准第三轮统计分析

## 1. 测试结论

2026-08-12 09:48–09:51，在 RK3506 板卡 `192.168.100.140` 上使用当天09:45重新构建的
`TestTRMmain`，完成500–510 MHz、1 MHz步进的11点启动校准测试。每个频点尝试100次
ACM初始化校准，完成后输入`q`退出。

| 指标 | 结果 |
|---|---:|
| 测试频点 | 11 |
| 达到100次的频点 | 2（500、502 MHz） |
| 总有效校准次数 | 522/1100 |
| 平均有效次数 | 47.45/100 |
| 最低有效次数 | 0（505 MHz） |
| 正常退出 | 11/11 |

结论如下：

1. 500–502 MHz仍接近可用边界，分别为100、99、100次。
2. 从503 MHz开始明显下降；503 MHz尚有90次，504 MHz下降至36次，505 MHz为0次。
3. 506–510 MHz没有单调下降，而是2、29、15、1、50次。这再次证明高频端不是简单的
   固定低通截止，而是存在较强的频率选择性和运行间波动。
4. 500–510 MHz三轮测试中，只有502 MHz三次都是100/100；500、501 MHz三轮最低值
   都是99次。503 MHz以上没有任何一个频点在三轮中保持100次。
5. 本轮使用了新构建二进制，不能把本轮与前两轮的差异全部解释为硬件随机波动；不过
   “503 MHz以上总体不稳定”的结论在新旧两个二进制上都成立。

三轮数据可以将频点分为三类：

- **稳定频点：502 MHz。** 三轮全部100/100。
- **边界频点：500、501 MHz。** 三轮最低99/100，偶尔损失一次，但整体稳定。
- **不稳定频点：503–510 MHz。** 有效次数显著低于100，且不同轮次变化很大。

503–510 MHz的恢复峰位置并不固定。例如第一轮507 MHz为80，第二轮506 MHz为82，第三轮
503 MHz为90；这不支持简单的“频率越高SNR越低”模型，更像阵列耦合/多径深衰落位置、
自动增益搜索或某些通道/tone状态发生变化。

## 4. 因子均值与方差分析

本轮所有有因子频点的CH1–CH7平均复方差均值为`2.7723e-3`。其中506 MHz的平均复方差
达到`1.1960e-2`，但只有2个有效样本，不能作为稳定统计结论。

分通道看，在有效样本中CH7方差最大，其所有频点复方差平均值约`1.1666e-2`；但该数值
受到506 MHz的两个高波动样本明显拉高。只统计样本数不少于10的频点时，CH7复方差平均值
约`4.8401e-3`，仍高于其他通道。CH5和CH3次之。

因此，本轮仍建议优先排查CH7，其次CH5、CH3。但总有效次数是主要判据，少样本频点的
方差只能作为辅助证据。
