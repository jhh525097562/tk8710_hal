# 终端信道相关性测试方案

| 场景 | 输入/操作 | 通过标准 |
|---|---|---|
| 符号扩展 | 0x00000、0x7FFFF、0x80000、0xFFFFF | 分别得到 0、524287、-524288、-1 |
| 相同/缩放/相移信道 | 构造对应 8 天线向量 | 相关性为 1 |
| 正交信道 | 构造正交复向量 | 相关性为 0 |
| 去重排序 | 乱序输入 0x882CC501、0x882CC5FF 等 | 高 3 byte 去重，最后值覆盖且升序输出 |
| 二维表 | N 个非重复终端 | 行列 ID 均升序；对角线为 1，上三角有 N(N-1)/2 个结果，下三角留空 |
| 边界 | 空列表、0/1 用户、零向量 | 不崩溃，零向量输出 N/A |
| 文件错误 | 日志目录或文件不可写 | 控制台报错，IPC 接收路径继续 |
| 构建 | RK3506 构建 `tk8710_gw` | 编译链接通过 |

最终执行 `git diff --check`、目标源静态检查和 RK3506 交叉构建；板端多终端实测单独记录为硬件验证。
