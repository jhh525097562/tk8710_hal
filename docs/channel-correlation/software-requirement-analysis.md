# 终端信道相关性软件需求分析

## 目标

网关在每次 TRM 接收回调中，基于接收终端的 8 天线复数 AH 向量计算终端两两信道相关性，供现场分析终端信道的空间相似程度。

## 功能需求

- 终端键为完整 `userId` 的高 3 byte，低 1 byte 网络 ID 不参与识别。
- 单次回调内按终端键去重；重复终端采用最后一条 AH，并按终端键升序排列。
- 输出二维相关性表，第一行和第一列为排序后的终端 ID；对角线填 1，上三角填相关性，下三角留空。
- 结果仅追加到 `/userdata/8710log/correlation.txt`，正常情况下不输出到控制台。
- 日志批次头记录超帧号、系统帧号、原始用户数和去重后终端数。
- 文件系统错误和零范数信道不得中断既有接收与 IPC 上报流程。

## 约束与验收

AH 为 8 组 `I/Q`，每分量取低 20 bit，并按二补码解释为 Q12.7。相关性采用复数共轭内积归一化，结果范围为 0 到 1；零范数输出 `N/A (zero norm)`。不修改 HAL/TRM 公共接口和协议。
