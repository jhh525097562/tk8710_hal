# 终端信道相关性概要设计

## 数据流

`OnTrmRxData` 接收 `TRM_RxDataList`，调用局部相关性处理函数。处理函数复制本批次的终端键和 `beam.ahData`，完成去重、排序及两两计算，随后以固定 12 字符列宽的上三角二维表追加到文件。正常结果不写控制台。原有计数、IPC 上报和采集流程保持原顺序。

## 设计决策

- 使用固定 128 项栈数组，与 TRM 单批最大用户数一致，不引入动态内存和跨回调状态。
- 使用 `double` 计算内积实部、虚部和能量；Q7 比例在归一化中抵消。
- 日志打开失败仅输出一次错误并继续控制台计算，避免影响业务回调。
- 使用现有 RK3506 构建脚本提供的 `-lm`，不改变公共构建接口。
