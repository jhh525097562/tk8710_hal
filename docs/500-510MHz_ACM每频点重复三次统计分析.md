# 500–510 MHz ACM每频点重复三次统计分析

## 1. 测试结论

2026-08-12 10:32–10:40，在RK3506板卡`192.168.100.140`上，对500–510 MHz按1 MHz
步进测试，每个频点连续启动3次，共执行33次。每次启动均尝试100次ACM初始化校准，完成后
由测试技能输入`q`退出。

| 指标 | 结果 |
|---|---:|
| 频点数 | 11 |
| 每频点重复次数 | 3 |
| 总运行次数 | 33 |
| 达到100/100的运行 | 21/33（63.64%） |
| 有效因子总数 | 3207/3300（97.18%） |
| 三次全部通过的频点 | 500、501、505、506、508 MHz |
| 三次均未完全通过的频点 | 509、510 MHz |
| 33次正常退出 | 33/33 |

本轮使用同一个10:28构建版本，因而可以直接评估短时间内的重复性。主要结论：

1. **500、501、505、506、508 MHz重复性最好**，三次均为100/100。
2. **502、503、504、507 MHz属于轻度或中度随机失效**。三次均值分别为98.67、97.67、
   96.00和99.33次，至少有一次达到100，但并非3/3通过。
3. **509、510 MHz问题最明确**。509 MHz三次为84、94、99，510 MHz为63、98、94，
   三次都未达到目标；510 MHz标准差19.16、极差35，是重复性最差的频点。
4. 从第一次到第三次，整轮有效次数由1039升到1077、再升到1091，均值由94.45升到
   97.91、99.18。可能存在设备启动、温度、AGC/增益状态或环境稳定过程，但当前只有一次
   顺序扫频，尚不能确认是时间趋势。
5. 频率响应不呈简单单调下降：505、506和508 MHz可以3/3通过，但507、509、510 MHz
   不稳定。结果更符合频率选择性互耦/多径、特定通道或tone的SNR门限问题。

## 3. 每轮整体统计

| 轮次 | 有效次数总和/1100 | 平均值/100 | 100/100频点数 | 最小单点值 |
|---:|---:|---:|---:|---:|
| 第1次 | 1039 | 94.45 | 7 | 63 |
| 第2次 | 1077 | 97.91 | 6 | 88 |
| 第3次 | 1091 | 99.18 | 8 | 94 |

测试顺序为500 MHz连续3次，然后501 MHz连续3次，依次到510 MHz。因此上表“第1次、第2次、
第3次”不是三个完整的独立扫频周期，而是每个频点内部的重复序号。三次总体逐渐改善可能与
短时间重复启动有关，但也可能只是随机波动。若要验证温度或时间趋势，应改为完整执行三轮
`500→510 MHz`，或者采用随机频点顺序。

## 4. 因子均值和方差

因子按18位有符号、15位小数转换；通道稳定度使用`Var(I)+Var(Q)`。每频点三次因子的
CH1–CH7平均复方差如下：

| 频率 (MHz) | 因子幅度均值 | CH1–CH7平均复方差 |
|---:|---:|---:|
| 500 | 1.047502 | 0.00282410 |
| 501 | 1.024554 | 0.00321581 |
| 502 | 1.089574 | 0.00297865 |
| 503 | 1.085038 | 0.00256368 |
| 504 | 1.075481 | 0.00284875 |
| 505 | 1.075904 | 0.00338241 |
| 506 | 1.115263 | 0.00355555 |
| 507 | 1.248918 | 0.00643563 |
| 508 | 1.047439 | 0.00339307 |
| 509 | 1.049969 | 0.00361998 |
| 510 | 1.071069 | 0.00446400 |

507 MHz的平均复方差最高，虽然有效次数仍为100、98、100。这说明“校准因子分散程度”和
“是否达到100个有效结果”不是完全等价的指标。

按通道汇总，CH7平均复方差约`1.2430e-2`，明显高于CH3的`5.3266e-3`和其他通道；最大
单次值出现在507 MHz第1次，CH7复方差约`4.3249e-2`。CH7仍是最需要优先检查的链路，
其次为CH3和CH5。

## 5. 与此前单次测试的关系

此前09:48测试使用SHA256为`4e2b4dd...`的二进制，本轮使用`d4f7d577...`，不能直接用来
判断同一版本的自然波动。本轮内部33次均使用同一二进制，才是本报告重复性结论的依据。

与旧结果相比，本轮505、506、508 MHz明显改善，但509、510 MHz仍连续失败，说明新版本
并未完全解决高频端问题。若10:28版本包含增益验证或SNR补偿修改，应进一步结合代码差异和
每次保存的gain文件分析修改为何对部分频点有效。
