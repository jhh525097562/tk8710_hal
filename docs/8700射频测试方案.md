# 8700射频测试方案

## 1. 文档目的

本文用于指导 8700 射频测试板在 Windows JTOOL 环境下完成射频直流分量去除、射频发送功率测试和接收灵敏度测试。方案基于原《射频直流校准方案》扩展，测试程序统一使用 `Test8710RFTest.exe`，图形化操作可使用 `tools\rf_calibration_gui.py`。

本方案覆盖三类测试：

| 测试项 | 测试模式 | 目的 |
|--------|----------|------|
| 直流分量去除 | `test_select=0` | 调整 I/Q 直流补偿寄存器，使中心频率处直流分量满足要求 |
| 发送功率测试 | `test_select=1` | 验证指定 TX 增益和线损条件下的发射输出功率 |
| 接收灵敏度测试 | `test_select=2` | 验证指定速率模式和输入电平条件下的接收能力，并输出丢包统计 |

## 2. 测试环境

### 2.1 硬件环境

| 设备 | 用途 |
|------|------|
| 8700 射频测试板 | 单个射频模块 + TK8710 芯片，用于执行发射 Tone、接收灵敏度和直流补偿测试 |
| JTOOL/JSPI 工具 | 连接 TK8710，用于初始化芯片、配置 RF、读写寄存器 |
| 频谱仪 | 测量中心频率直流分量和发射频谱 |
| 功率计或频谱仪功率测量功能 | 测量发送功率 |
| 矢量信号源/信号源 | 产生接收灵敏度测试所需的 Mode 6 上行信号 |
| 固定衰减器/射频线缆 | 构造已知线损，本方案发送功率和接收灵敏度标准均按 `1 dB` 线损记录 |
| I2C 接口 | 连接射频模块，用于将最终直流补偿值写入射频 Flash 并回读 |

### 2.2 软件环境

| 软件/接口 | 要求 |
|-----------|------|
| `build_jtool\Test8710RFTest.exe` | 支持三种射频测试模式，支持 JTOOL 初始化、TX Tone、RX sensitivity 和 TCP 协议 |
| `tools\rf_calibration_gui.py` | 支持启动测试程序、连接 TCP、寄存器读写、I/Q 组字、统计刷新和日志自动刷新 |
| JTOOL 驱动 | 支持 Windows 下 JTOOL SPI 访问和 TK8710 全局寄存器读写 |
| I2C 写 Flash 工具或接口 | 支持写入最终 I/Q 直流补偿值并回读确认 |

## 3. 测试程序参数

`Test8710RFTest.exe` 命令格式如下：

```powershell
.\Test8710RFTest.exe [rate_mode frequency tx_gain rx_gain test_select] [--tcp] [--bind IP] [--port PORT]
```

参数说明：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `rate_mode` | `6` | 速率模式，支持 `5,6,7,8,9,10,11,18` |
| `frequency` | `509100000` | RF 中心频率，单位 Hz |
| `tx_gain` | `0x2a` | RF 发送增益，支持十进制或 `0x` 十六进制 |
| `rx_gain` | `0x7e` | RF 接收增益，支持十进制或 `0x` 十六进制 |
| `test_select` | `0` | `0`=直流分量去除，`1`=发送功率测试，`2`=接收灵敏度测试 |
| `--tcp` | - | 启用 Windows TCP 服务模式 |
| `--bind` | `127.0.0.1` | TCP 监听 IPv4 地址 |
| `--port` | `12879` | TCP 监听端口 |

三种测试模式对应软件行为：

| `test_select` | 软件配置 | 典型命令 |
|---------------|----------|----------|
| `0` | 配置 TX Tone，`TxToneConfig.gain=0x00`，用于直流分量去除 | `.\Test8710RFTest.exe 6 509100000 0x2a 0x7e 0 --tcp` |
| `1` | 配置 TX Tone，`TxToneConfig.gain=0x40`，用于发送功率测试 | `.\Test8710RFTest.exe 6 509100000 0x2a 0x7e 1 --tcp` |
| `2` | 配置 Slave 接收时隙，启动连续接收并输出 `STATS/LOG` | `.\Test8710RFTest.exe 6 509100000 0x2a 0x7e 2 --tcp` |

## 4. 直流分量去除测试

### 4.1 频谱仪设置

频谱仪用于读取发射中心频率处的直流分量。测试过程中频谱仪设置保持不变：

| 参数 | 设置 |
|------|------|
| Center Frequency | 与测试程序配置频点一致，本方案示例为 `509100000 Hz` |
| Span | `200 kHz` |
| RBW | `1 kHz` |
| VBW | `1 kHz` |
| Trace Mode | `Average` |
| AVG Count | `10` |
| 读数位置 | 中心频率处的直流分量 |

每次写入新的直流补偿寄存器值后，等待 `500 ms`，再读取并记录频谱仪中心频率处的直流分量。

### 4.2 直流补偿寄存器格式

校准时写入直流补偿寄存器的值为 `32 bit`：

```text
bit[31:16] = I 路直流补偿值
bit[15:0]  = Q 路直流补偿值
```

I/Q 两路均按 `16 bit` 有符号补偿值处理。寄存器写入格式如下：

```text
寄存器值 = ((I_DC & 0xFFFF) << 16) | (Q_DC & 0xFFFF)
```

示例：

```text
I_DC = 0x0400
Q_DC = 0x0000
写入值 = 0x04000000
```

本次校准使用的直流补偿寄存器地址为 `0x08c8`。通过 TCP 或 GUI 写入时，地址和值示例如下：

```text
WRITE 0x08C8 0x04000000
```

### 4.3 启动流程

1. 连接 8700 射频测试板、JTOOL、频谱仪和 I2C 接口。
2. 频谱仪中心频率设置为 `509.1 MHz`，并按第 4.1 节设置 Span、RBW、VBW、Trace 和平均次数。
3. 在 `build_jtool` 目录启动直流分量去除模式：

   ```powershell
   .\Test8710RFTest.exe 6 509100000 0x2a 0x7e 0 --tcp
   ```

4. 等待 TK8710、RF 和 Tone 初始化完成。
5. 通过 GUI 或 TCP 先写入全 0 直流补偿值：

   ```text
   WRITE 0x08C8 0x00000000
   ```

6. 写入后等待 `500 ms`，读取频谱仪中心频率处的直流分量，作为初始直流分量记录。

### 4.4 I/Q 迭代方法

校准采用 I/Q 交替调整方式：

- 先调 I 路，再调 Q 路。
- 每次只调整一路，另一路保持上一次最优值不变。
- 每次写入后等待 `500 ms`，读取频谱仪中心频率直流分量。
- 若直流分量变小，说明当前调整方向有效，继续沿该方向调整。
- 若直流分量变大，回退到上一次较优值，并切换到另一路或减小步进。
- 当调整无明显改善时，降低步进并在 I/Q 两路之间反复微调。

建议粗调步进从 `0x0200` 开始，细调步进降到 `0x0100`。如需进一步压低直流分量，可继续降低到 `0x0080` 或 `0x0040`，但记录表中必须标明实际使用步进。

### 4.5 直流分量去除通过标准

满足以下条件时，直流分量去除测试通过：

1. 频谱仪中心频率处的直流分量小于 `25 dB`。
2. 当前 I/Q 值继续调整后无明显改善，且回退后仍满足小于 `25 dB` 的要求。
3. 已记录最终寄存器地址、I 路值、Q 路值、32 bit 写入值和最终频谱仪读数。
4. 最终 I/Q 值已写入射频 Flash，并完成 I2C 回读确认。
5. 重新初始化后复测，直流分量仍满足小于 `25 dB`。

## 5. 发送功率测试

### 5.1 测试连接

发送功率测试建议使用以下连接：

```text
8700 RF输出口 -> 1 dB线损/衰减链路 -> 功率计或频谱仪
```

测试前确认：

- 功率计或频谱仪输入功率范围满足被测输出功率。
- 仪表频率设置为测试频点，例如 `509.1 MHz`。
- 线损按 `1 dB` 记录，并在功率结果中修正。

### 5.2 启动发送功率测试

在 `build_jtool` 目录启动发送功率测试模式：

```powershell
.\Test8710RFTest.exe 6 509100000 0x2a 0x7e 1 --tcp
```

关键配置：

| 项目 | 设置 |
|------|------|
| `rate_mode` | `6` |
| `frequency` | `509100000 Hz` |
| `tx_gain` | `0x2a` |
| `rx_gain` | `0x7e`，本测试不作为判定项 |
| `test_select` | `1` |
| `TxToneConfig.gain` | `0x40` |
| 线损 | `1 dB` |

### 5.3 功率读数和修正

发送功率按下式记录：

```text
射频口输出功率 = 仪表读数 + 线损
```

本方案线损为 `1 dB`，因此：

```text
射频口输出功率 = 仪表读数 + 1 dB
```

示例：

```text
仪表读数 = 23.0 dBm
线损 = 1.0 dB
射频口输出功率 = 24.0 dBm
```

### 5.4 发送功率通过标准

发送功率测试通过标准：

| 项目 | 标准 |
|------|------|
| `tx_gain` | `0x2a` |
| 线损 | `1 dB` |
| 修正后射频口输出功率 | `>= 24 dBm` |

若仪表读数未修正线损，则在 `1 dB` 线损条件下，仪表读数应不低于 `23 dBm`。测试报告中必须同时记录仪表原始读数、线损和修正后功率。

### 5.5 发送功率记录表

|------|------------|------|-----------|---------------------|----------|------|------------|------|------|

## 6. 接收灵敏度测试

### 6.1 测试连接

接收灵敏度测试建议使用单天线链路：

```text
信号源RF输出 -> 1 dB线损/衰减链路 -> 8700单天线RF输入
```

测试前确认：

- 只连接并启用单天线链路，避免多天线合路带来额外增益或损耗。
- 信号源输出波形与 Mode 6 上行接收配置匹配。
- 信号源频点与测试程序 `frequency` 一致。
- 线损按 `1 dB` 记录。

### 6.2 启动接收灵敏度测试

在 `build_jtool` 目录启动接收灵敏度模式：

```powershell
.\Test8710RFTest.exe 6 509100000 0x2a 0x7e 2 --tcp
```

关键配置：

| 项目 | 设置 |
|------|------|
| `rate_mode` | `6` |
| `frequency` | `509100000 Hz` |
| `tx_gain` | `0x2a`，本测试不作为判定项 |
| `rx_gain` | `0x7e` |
| `test_select` | `2` |
| 接收模式 | Slave 连续接收 |
| 天线链路 | 单天线 |

### 6.3 信号源设置

| 参数 | 设置 |
|------|------|
| 波形/速率模式 | Mode 6 |
| RF频点 | 与测试程序一致，例如 `509100000 Hz` |
| 输出功率 | `-132 dBm` |
| 天线 | 单天线 |
| 线损 | `1 dB` |

本方案验收以信号源设置 `-132 dBm`、单天线、线损 `1 dB` 的统一工况为准。若需要记录板端折算输入功率，可按下式记录：

```text
板端折算输入功率 = 信号源输出功率 - 线损 = -132 dBm - 1 dB = -133 dBm
```

### 6.4 丢包统计和实时观察

接收灵敏度模式下，测试程序通过 TCP 提供两类实时信息：

| 命令 | 说明 | 示例响应 |
|------|------|----------|
| `STATS` | 当前累计包数、丢包数、丢包率和最近一次用户信号质量 | `OK STATS mode=2 total=100 lost=0 ... loss=0.00 ...` |
| `LOG` | 最新一条接收或丢包日志，包含递增 `seq` | `OK LOG seq=12 RX user=0 freq=0Hz rssi=-55 snr=18 total=100 lost=0` |

GUI 页面默认勾选“自动刷新日志”，连接后会周期性发送 `LOG`，并只在 `seq` 变化时追加到日志窗口。手动点击“刷新统计”可读取 `STATS` 快照。

接收日志含义：

| 日志字段 | 含义 |
|----------|------|
| `RX user` | 当前 CRC 正确的用户索引 |
| `freq` | 接收频偏换算值 |
| `rssi` | 接收 RSSI 换算值 |
| `snr` | 接收 SNR 换算值 |
| `total` | 累计接收统计周期数 |
| `lost` | 累计丢包数 |

### 6.5 接收灵敏度通过标准

接收灵敏度测试通过标准：

| 项目 | 标准 |
|------|------|
| 速率模式 | Mode 6 |
| 信号源设置 | `-132 dBm` |
| 天线 | 单天线 |
| 线损 | `1 dB` |
| 接收状态 | `LOG` 持续出现 `RX user=...`，`STATS` 中 `total` 持续增长 |
| 丢包统计 | 标准工况下 `lost` 不增加，统计丢包率为 `0%` |

如果现场另有项目级丢包率门限，应在测试报告中明确门限，并以 `STATS` 输出的 `lost/total/loss` 作为判定依据。若 `LOG` 持续出现 `RX lost` 或 `STATS` 中 `lost` 持续增加，则判定为不通过。

## 7. Windows TCP 和 GUI 操作

### 7.1 TCP 命令协议

协议使用 UTF-8/ASCII 文本，每条命令必须以换行符结尾。地址和值支持十进制或 `0x` 前缀十六进制。

| 命令 | 示例 | 成功响应 |
|------|------|----------|
| 连通检查 | `PING` | `OK PONG` |
| 读取寄存器 | `READ 0x08C8` | `OK READ 0x08C8 0x04000000` |
| 写入并回读 | `WRITE 0x08C8 0x04000000` | `OK WRITE 0x08C8 0x04000000 READBACK 0x04000000` |
| 读取统计 | `STATS` | `OK STATS ...` |
| 读取最新日志 | `LOG` | `OK LOG seq=... ...` |
| 断开当前客户端 | `QUIT` | `OK BYE` |
| 停止 TCP 服务并退出程序 | `SHUTDOWN` | `OK SHUTDOWN` |

常见错误响应包括：

```text
ERR INVALID_COMMAND
ERR INVALID_ADDRESS
ERR INVALID_VALUE
ERR READ_FAILED 错误码
ERR WRITE_FAILED 错误码
ERR READBACK_FAILED 错误码
ERR STATS_UNAVAILABLE
ERR LOG_UNAVAILABLE
```

### 7.2 GUI 启动

在工程根目录运行：

```powershell
python tools\rf_calibration_gui.py
```

页面默认连接 `127.0.0.1:12879`，默认本机程序为 `build_jtool\Test8710RFTest.exe`，提供以下功能：

- 一键启动 `Test8710RFTest.exe` 并自动等待 TCP 服务完成连接；
- 配置速率模式、频率、TX gain、RX gain 和测试模式；
- 连接、断开和 `PING` 连通检查；
- 读取/写入 TK8710 全局寄存器并自动检查回读；
- 分别输入 `I_DC` 和 `Q_DC`，自动生成 `32 bit` 直流补偿寄存器值；
- 手动刷新 `STATS`，并自动刷新 `LOG` 用于实时观察灵敏度测试；
- 发送 `SHUTDOWN` 停止 TCP 服务。

页面默认参数：

| 参数 | 默认值 |
|------|--------|
| 速率模式 | `6` |
| 频率 | `509100000` |
| TX gain | `42`，即 `0x2a` |
| RX gain | `0x7e` |
| 测试模式 | `0` |
| 自动刷新日志 | 开启 |
