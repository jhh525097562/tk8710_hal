**版本：** V1.0
**日期：** 2026-09-02

# 1. 执行约束

- Git 隔离：shared-working-tree serial agent mode。
- 集成方式：patch-ready mode，不暂存、不提交、不推送、不创建 PR。
- 写入并发上限：1；本次不启用子代理。
- 必须保留 `test/example/tk8710_gw.c` 现有修改及整个 `3506uart/` 用户资料。

# 3. 任务定义

## T-01 协议/API 契约测试与公共接口

- 范围：新增公共头文件和协议解析测试；不修改既有 HAL API。
- 实现：按详细设计定义错误码、配置、上下文、周期、状态、诊断与健康类型；先建立字段解析、健康分类、事件穿插和命令顺序测试夹具。
- 依赖：无。
- 工作量：M。
- 验收：公共合同与设计一致；测试在实现前可证明关键失败场景，在 T-02 后全部通过。
- 诊断：`-std=c99 -Wall -Wextra -Werror` 主机编译；无 LSP 时以编译器诊断替代。
- 回归：公共 include 路径和 C/C++ guard。
- 回滚：删除本任务新增文件；不触碰用户文件。
- 完成信号：文件清单、测试命令及结果、Git patch-ready 状态。

## T-02 PPS UART API 实现

- 范围：新增 PPS 实现模块；仅为构建接入所需时修改构建清单。
- 实现：POSIX termios/poll、单调总超时、CR/LF 行分帧、EVENT 保存、OK/ERR 区分、严格 KV 解析、结构化查询、详细诊断、健康分类和 GPIO 复位重连；非 RK3506 返回 UNSUPPORTED。
- 不允许：自动发送 `OUT ON`/设置周期；底层 API 不实现监控复位策略。
- 依赖：T-01。
- 工作量：L。
- 验收：T-01 测试通过；错误码可区分打开、读写、超时、协议、解析、溢出、GPIO。
- 诊断：`-std=c99 -Wall -Wextra -Werror`；RK3506 交叉编译。
- 回归：现有静态库符号和构建不退化。
- 回滚：移除新增模块及对应构建项。
- 完成信号：测试与构建结果、公共符号检查、Git patch-ready 状态。

## T-03 监控测试程序与构建集成

- 范围：新增 RK3506 示例程序和目标；更新 CMake/Shell 构建。
- 实现：默认 10 秒、2 秒轮询、60 秒启动宽限、连续 3 次异常、30 秒复位冷却、最多 3 轮恢复；首次及复位后都严格 `OUT ON` 后 `SET PERIOD 10`；捕获 SIGINT/SIGTERM 且不发送 `OUT OFF`。
- 依赖：T-02。
- 工作量：M。
- 验收：模拟命令日志断言配置顺序；状态机边界测试通过；目标交叉编译成功。
- 诊断：编译器 `-Wall -Wextra`；构建脚本语法检查。
- 回归：`build_rk3506.sh` 现有 target 选择保持兼容。
- 回滚：移除示例目标及构建项，不影响库 API。
- 完成信号：二进制路径、命令顺序证据、Git patch-ready 状态。

## T-04 软件回归和交付检查

- 范围：全部本次改动和相关 RK3506 构建路径，只读审查用户既有修改。
- 实现：运行协议/状态机测试、交叉构建、符号和差异检查；执行代码质量审查并修复本需求引入的问题；更新进度证据。
- 依赖：T-03。
- 工作量：M。
- 验收：所有可在当前环境执行的测试通过；失败或未执行项明确记录。
- 诊断：`git diff --check`、编译器警告、构建退出码。
- 回归：新增 API、示例目标、既有库完整构建。
- 回滚：按文件级反向补丁回退，禁止 destructive Git 命令。
- 完成信号：完整软件证据、变更清单、未决硬件项、Git patch-ready 状态。

## H-01 板端与仪器验收

- 范围：RK3506、AG32、UART/GPIO 接线和 PPS_OUT 测量。
- 依赖：T-04；可访问板卡和仪器。
- 工作量：M。
- 验收：运行最终二进制；记录版本、配置顺序、健康轮询、故障注入、诊断、GPIO 恢复；示波器或计数器测得 10 秒周期。
- 说明：硬件条件不可用时标记未执行，不阻塞源码 patch-ready，但阻止宣称板端验收通过。

# 7. V1.1 网关 GPS/PPS 集成任务

```text
T-06 网关 GPS 状态策略测试
  -> T-07 8710 同步寄存器与 ACM 外部同步
  -> T-08 网关启动、周期配置和运行监测
  -> T-09 软件回归与双板验证
```

- `T-06`：先建立 GPS 基础就绪、完整 PPS 健康、连续 3 次判定、周期换算和退出码测试。
- `T-07`：激活 `slotCfg.local_sync`；普通启动与快速启动统一映射同步位；外部同步 ACM 校准后立即触发。
- `T-08`：启动前探测并等待 GPS，NS 配置后按 `OUT ON`、`SET PERIOD` 配置计算周期，运行期监测并统一退出。
- `T-09`：运行全部 PPS 测试和 RK3506 交叉构建；分别在 `.140` 无模块板和 `.62` 有模块板保存运行证据。
- 集成方式继续使用 shared-working-tree patch-ready；不暂存、不提交、不覆盖板上现有 `tk8710_gw`。
