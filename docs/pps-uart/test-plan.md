## 4.3 系统与板端测试

在 RK3506 上运行最终测试程序，保存完整 stdout/stderr 和设备版本。分别观察正常运行、断开 UART、制造 PPS 丢失/异常以及设备复位后的恢复。

# 6. 异常与边界

- UART 打开失败、写失败、读取失败、2 秒超时。
- 设备返回 `ERR BAD PERIOD` 或响应周期与请求不一致。
- 单行/累计响应超限，数值溢出，必需字段缺失。
- 启动 60 秒未健康、GPS 临时失锁、HOLD、BAD、RESYNC。
- 诊断查询部分失败时仍保留成功项并继续恢复。
- GPIO 拉低失败或拉高失败必须报告 GPIO 错误，不伪装成成功复位。
