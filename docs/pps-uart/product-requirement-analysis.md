# 1. 产品概述

## 1.1 系统简介

TK8710 完成时隙周期计算后，RK3506 使用外接 UART 将周期配置给 AG32 PPS 设备。AG32 输出周期脉冲，TK8710 在该脉冲约束下工作。系统还需持续读取设备状态，并在持续故障时通过复位 GPIO 恢复设备。

## 1.2 系统组成与数据流

`TK8710 业务/测试程序 -> PPS 公共 API -> /dev/ttyS4 -> AG32 PPS 设备 -> PPS_OUT -> TK8710`

异常恢复链路为 `PPS 公共 API -> libgpiod -> gpiochip1 line 19 -> AG32 reset`。

## 1.3 产品定位与适用场景

该能力是 TK8710 HAL 在 RK3506 Linux 平台上的外部定时设备管理组件，供业务程序和板端测试程序复用。不替代 AG32 固件、GPS 模块管理或仪器波形测量。

# 2. 产品特征

- 使用现有 AG32 ASCII 行协议，默认 `/dev/ttyS4`、115200 8N1。
- 提供周期配置、输出启停、状态读取、详细诊断和硬件复位 API。
- 将协议字段解析为定宽 C 数据结构，同时忽略未知字段以保持向前兼容。
- 对主动 `EVENT` 与命令 `OK/ERR` 响应进行区分。
- 持续异常才触发复位，避免启动、GPS 暂时失锁时形成复位循环。

# 3. 产品组成

| 组成 | 职责 |
| --- | --- |
| RK3506 | 运行 PPS API 和测试程序 |
| AG32 PPS 设备 | 接受周期配置、输出脉冲、提供状态和诊断 |
| UART | ASCII 命令和状态通道 |
| GPIO1_19 | AG32 低电平有效复位控制 |
| 测试仪器 | 从外部确认实际脉冲周期和电气波形 |

# 4. 功能规格

| ID | 功能需求 |
| --- | --- |
| FR-01 | 调用者可初始化和关闭独立 PPS 设备连接。 |
| FR-02 | 调用者可配置以秒为单位的脉冲周期，并获知命令是否被设备接受。 |
| FR-03 | 调用者可开启或关闭 PPS 输出。 |
| FR-04 | 调用者可读取当前周期、待生效周期和周期切换状态。 |
| FR-05 | 调用者可读取结构化运行状态，不将状态压缩为单一布尔值。 |
| FR-06 | 调用者可在异常时采集 PPS、OUT、SYNC、GPS 和 RMC 诊断。 |
| FR-07 | 调用者可通过配置的 GPIO 对外部设备执行低有效复位并重新建立 UART。 |
| FR-08 | 提供健康判定辅助能力，但保留原始状态字段供业务自行决策。 |
| FR-09 | 测试程序必须按 `OUT ON`、`SET PERIOD 10` 顺序配置，首次启动和复位后顺序一致。 |
| FR-10 | 测试程序每 2 秒轮询；启动宽限 60 秒；连续 3 次故障后采集诊断并恢复。 |
| FR-11 | 两次复位间隔至少 30 秒；连续恢复最多 3 次，失败后非零退出。 |
| FR-12 | 收到 SIGINT/SIGTERM 时关闭本地资源，但不主动发送 `OUT OFF`。 |

# 5. 性能与运行约束

| 项目 | 要求 |
| --- | --- |
| 命令响应 | 默认 2000 ms 超时，可配置 |
| 轮询周期 | 测试程序默认 2000 ms |
| 复位脉宽 | GPIO 低电平 100 ms |
| 复位限流 | 间隔不少于 30 秒，最多连续 3 次 |
| 平台 | RK3506 Linux；非 RK3506 返回不支持 |
| 线程模型 | 单个上下文不支持并发命令；调用方负责串行化 |

# 6. 风险与约束

- `OK PERIOD` 仅代表接受配置，不能证明周期已经生效或物理引脚有正确波形。
- `OUT=1`、`ALIGN=1` 单独均不足以证明健康；必须组合判断。
- UART 状态只能作为软件证据；最终周期需用示波器或计数器验证。
- 当前 `3506uart/` 为用户已有未跟踪资料，本功能不得覆盖或改写其中内容。
- 当前 `test/example/tk8710_gw.c` 的用户修改不属于本需求。

# 7. 验收标准

- 公共 API 可完成连接、`OUT ON`、10 秒周期配置、状态和诊断读取、GPIO 复位。
- 模拟协议测试证明未知字段和穿插事件不会破坏命令响应解析。
- 测试日志证明首次启动和每次复位后均严格先 `OUT ON`、再 `SET PERIOD 10`。
- RK3506 交叉编译通过且无新增编译警告。
- 板端日志证明健康轮询、连续异常诊断和受限复位流程符合要求。
- 仪器测得 PPS_OUT 周期为 10 秒；如未执行仪器验证，必须明确标为未完成硬件验收。
