# E5062A 天线频率响应与多天线互耦测试步骤

## 1. 测试目的

本文使用 Agilent E5062A（300 kHz～3 GHz）验证 8 天线系统在 470～510 MHz 内的两个问题：

1. 天线安装后是否存在谐振点偏低、高频端匹配变差等频率响应问题；
2. 7TX1RX/7RX1TX 校准中，任意两根天线之间是否存在过强或频率相关的互耦。

E5062A 可以完成：

- 每根天线端口的 `S11`、回波损耗和 VSWR；
- 任意天线对之间的 `S21`、`S12` 幅度和相位；
- 8 天线共 28 组天线对的耦合矩阵；
- 裸天线、安装到整机后和改变周围环境后的对比。

E5062A 不能通过普通台面接线直接测出天线的绝对增益和总辐射效率。S11 好只表示端口匹配较好，
不保证实际辐射效率一定高。绝对增益/效率需要暗室、标准增益天线、转台或其他专用方法。

## 2. 安全要求

本测试是无源天线测试，必须满足：

- 8 个天线端口全部与射频模块、PA、LNA和射频开关断开；
- 射频模块断电，不运行 TX Tone、BCN、业务发送或互易性校准；
- E5062A PORT 1、PORT 2 只能连接无源天线、校准件、测试线或 50 Ω负载；
- 禁止把正在工作的PA输出连接E5062A；
- 测试期间不得拆装带电射频接口；
- 雷雨天气或附近存在大功率发射机时，不要测试室外天线；
- 校准后不得更换测试线、转接头或改变校准面。

> **不要通过软件把开关切到TX后直接测整块有源模块。** 本文测量的是天线和天线互耦，
> 校准面应位于天线馈电口。PA上电状态下从RF_ANT反向看到的S11不是天线S11。

## 5. 测试环境搭建

### 5.1 正式安装状态测试

该状态用于回答“实际8天线整机是否存在频率偏移和互耦”。

1. 天线必须安装在最终外壳、地板、支架和实际位置上；
2. 保持天线间距、倾角、极化方向与产品一致；
3. 断开8个射频模块，只保留无源天线和馈线；
4. 未接E5062A的其余6个天线端口全部接50 Ω负载；
5. 整机放在非金属支架上，建议离地面、墙壁和大型金属物体至少1 m；
6. 如果产品最终安装时附近必然存在金属结构，应保留该结构并记录尺寸、距离；
7. 测试线从天线地板背面或固定方向引出，不要横跨天线辐射面；
8. 用胶带或非金属夹具固定测试线，测量过程中不得改变走线；
9. 操作者退到固定位置，不要在扫描过程中靠近或触碰天线；
10. 关闭附近对讲机、无线数传设备和其他可能影响测试的发射机。

### 5.2 环境稳定性要求

天线间S21包含直达耦合和房间反射。普通实验室不能完全等同于暗室，因此必须保证：

- 桌面、墙壁、机柜、人体位置在一组测试中保持不变；
- 不要一边移动电缆一边扫描；
- 每组曲线至少连续测两次；
- 两次曲线相差超过1 dB时，先处理环境或接线稳定性；
- 正式结果以最终安装状态为主，吸波材料测试仅用于诊断多径。

### 5.3 建议的三种对比状态

| 状态 | 搭建方式 | 用途 |
|---|---|---|
| A：单天线基线 | 单根天线远离其他天线和金属物 | 获得天线自身大致谐振位置 |
| B：整机安装 | 8根天线全部安装，其余端口50 Ω终接 | 获得实际S11和互耦 |
| C：环境扰动 | 在B基础上移动整机或加吸波材料 | 区分固定互耦与空间多径 |

如果S11从A到B明显移动，说明安装结构或天线互耦造成失谐。如果S21凹点随着整机移动或吸波材料
位置变化，说明空间多径占比较大；如果曲线基本不动，则更偏向固定的天线近场互耦。

## 6. E5062A统一仪器配置

### 6.1 恢复初始状态

1. 确认PORT 1、PORT 2没有连接任何主动射频源；
2. 打开E5062A，等待启动完成；
3. 按前面板 **Preset**；
4. 如出现确认菜单，按屏幕右侧 **OK** 或 **Preset** 软键；
5. 按 **Channel Max**，使当前通道占满屏幕。

本文中“**Cal** → **Calibrate**”表示先按前面板实体Cal键，再按屏幕右侧对应软键。
不同固件的软键名称可能略有差异，应选择同义菜单。

### 6.2 设置频率

1. 按 **Start**，输入 `470`，按 **MHz**；
2. 按 **Stop**，输入 `510`，按 **MHz**；
3. 检查屏幕底部确认为 `START 470 MHz`、`STOP 510 MHz`。

### 6.3 设置扫描参数

1. 按 **Sweep Setup**；
2. 按 **Points**，输入 `801`，按 **Enter**；
3. 按 **IF Bandwidth** 或 **IFBW**，输入 `1`，按 **kHz**；
4. 按 **Power** → **Power/Level**，输入 `-5`，按 **dBm** 或 **Enter**；
5. 按 **Avg** → **Averaging On**；
6. 按 **Averaging Factor**，输入 `8`，按 **Enter**；
7. 按 **Avg** → **Restart** 或 **Clear Average**，重新开始平均。

推荐参数汇总：

| 参数 | 设置 |
|---|---:|
| Start/Stop | 470/510 MHz |
| Points | 801 |
| 频率间隔 | 约50 kHz |
| Source Power | -5 dBm |
| IFBW | 1 kHz |
| Averaging | 8次 |
| Format | Log Mag；相位测试时Phase |

无源天线可以承受-5 dBm测试信号。若S21低于仪器噪底，可先把平均次数提高到16或把IFBW降低到
300 Hz；不要首先改变接线或移动天线。

## 7. 完整两端口SOLT校准

测量S11和S21时，推荐在两根测试线末端完成完整两端口校准。

### 7.1 选择校准件定义

1. 按 **Cal**；
2. 找到 **Cal Kit** 或 **Select Cal Kit**；
3. 选择与实际OPEN/SHORT/LOAD/THRU一致的校准件型号；
4. 如果找不到型号，不要随意选择外观相似的校准件，应查校准件标签和说明书。

错误的Cal Kit定义会产生系统性幅相误差。

### 7.2 进入两端口校准

1. 两根测试线分别固定连接E5062A PORT 1和PORT 2；
2. 两根测试线另一端暂不接天线；
3. 按 **Cal** → **Calibrate**；
4. 按 **2-Port Cal**、**Full 2-Port** 或同义软键；
5. 选择 **Port 1-2**。

### 7.3 校准PORT 1

在PORT 1测试线末端依次完成：

1. 接OPEN，等待稳定，按 **Port 1 Open**；
2. 拆OPEN、接SHORT，按 **Port 1 Short**；
3. 拆SHORT、接LOAD，按 **Port 1 Load**；
4. 等待每一项出现勾选或已测提示。

### 7.4 校准PORT 2

在PORT 2测试线末端依次完成：

1. 接OPEN，按 **Port 2 Open**；
2. 接SHORT，按 **Port 2 Short**；
3. 接LOAD，按 **Port 2 Load**。

### 7.5 THRU校准

1. 拆下两端LOAD；
2. 使用THRU直通件连接PORT 1和PORT 2测试线末端；
3. 保持接头和线缆静止；
4. 按 **Thru**、**Port 1-2 Thru** 或同义软键；
5. 如果菜单要求测反向THRU，按屏幕提示完成；
6. 按 **Done**、**Done 2-Port Cal** 或 **Return**；
7. 返回测量界面，确认状态栏显示 `Cor`、`C` 或 `Correction On`。

校准完成后，两根测试线的末端就是校准面。不得再增加未包含在校准中的转接头。

### 7.6 校准快速检查

1. 保持两根测试线通过THRU连接；
2. 按 **Meas** → **S21**，再按 **Format** → **Log Mag**；
3. 470～510 MHz内的S21应接近0 dB且较平坦；
4. 拆下THRU，分别给两个校准面接LOAD；
5. 查看S11和S22，应明显低于-10 dB；
6. 检查不通过时必须重做校准，不能用后处理强行修正。

## 8. 测量每根天线安装后的S11

### 8.1 接线

以ANT0为例：

```text
E5062A PORT 1 ── 测试线1 ── ANT0馈电口
ANT1～ANT7 ── 各接一个50 Ω负载
E5062A PORT 2 ── 测试线2 ── 50 Ω负载
```

不要让其余天线端口开路。开路端口会改变天线间耦合后的反射，导致结果与实际50 Ω射频模块
终接状态不同。

### 8.2 仪器操作

1. 按 **Meas** → **S11**；
2. 按 **Format** → **Log Mag**；
3. 按 **Avg** → **Restart/Clear Average**；
4. 等待8次平均完成；
5. 设置Marker：470、480、490、495、500、510 MHz；
6. 按 **Marker** → **Marker Search** → **Min**，记录最佳谐振点；
7. 按 **Marker Search** → **Max**，记录全频段最差S11；
8. 保存CSV和屏幕图片；
9. 依次改接ANT1～ANT7，每次只更改被测端口，其他端口继续50 Ω终接。

### 8.4 判断天线是否偏向低频

重点查看：

- 最深S11凹点是否位于495 MHz以下；
- 495～510 MHz的S11是否逐渐向0 dB上升；
- 八根天线是否具有相同趋势；
- 单天线基线状态正常、装入整机后才偏低；
- 某一根天线是否明显偏离其他七根。

通用参考是470～510 MHz内S11不高于-10 dB，但最终门限应由天线和系统指标确定。

## 9. 测量任意两根天线之间的S21互耦

### 9.1 接线

以ANT0和ANT1为例：

```text
E5062A PORT 1 ── 测试线1 ── ANT0
E5062A PORT 2 ── 测试线2 ── ANT1
ANT2～ANT7 ── 各接一个50 Ω负载
```

整机、天线、测试线和操作者位置必须固定。

### 9.2 测量S21幅度

1. 按 **Meas** → **S21**；
2. 按 **Format** → **Log Mag**；
3. 按 **Scale** → **Auto Scale**；
4. 按 **Avg** → **Restart/Clear Average**；
5. 等待8次平均完成；
6. 用Marker记录470、480、490、495、500、510 MHz的S21；
7. 按 **Marker Search** → **Max**，记录耦合最强点；
8. 按 **Marker Search** → **Min**，记录耦合最弱点或频率凹点；
9. 保存CSV和屏幕图片，命名为 `S21_ANT0_ANT1_日期`。

S21越接近0 dB，耦合越强；越负，隔离越好。例如-10 dB比-30 dB耦合强得多。

### 9.3 测量相位

1. 保存S21幅度后，按 **Format** → **Phase**；
2. 保持接线和环境不变；
3. 记录470、480、490、495、500、510 MHz的相位；
4. 保存CSV；
5. 按 **Format** → **Log Mag** 返回幅度显示。

相位对8710互易性校准很重要。若495 MHz以上相位快速旋转，同时幅度出现凹点，空间相消或
多路径叠加的可能性较高。

### 9.4 S12互易性复核

1. 不改变任何接线；
2. 按 **Meas** → **S12**；
3. 按 **Format** → **Log Mag**；
4. 等待平均完成并保存数据；
5. 比较同一频点的S21和S12。

无源、线性、静态天线系统理论上应满足S21≈S12。明显不一致首先检查：

- 环境或人体是否移动；
- 接头是否松动；
- 平均是否完成；
- 校准修正是否开启；
- 附近是否出现外部发射信号；
- 终端负载是否漏接。

不要把小于约1 dB的差异直接认定为天线不互易；应先评估测试重复性和仪器误差。

### 9.5 完成28组测量

按第4章顺序测完全部28组。每更换一组时：

1. 先记录当前组编号；
2. 只改变PORT 1、PORT 2对应的两根天线；
3. 其余6个端口全部接50 Ω；
4. 固定测试线后人员退开；
5. 重新清除平均，但不重新Preset；
6. 不改变频率、功率、IFBW和校准状态。

如果测试线或转接头发生变化，必须重新进行两端口校准。

## 11. 如何判断495～510 MHz SNR下降原因

### 11.1 天线频率响应/失谐证据

满足以下组合时，优先判断天线系统高频端性能下降：

- 多数天线的S11最佳点落在495 MHz以下；
- 多数天线的S11从495到510 MHz逐渐变差；
- 单天线基线正常，但整机安装状态变差；
- ACM SNR随天线S11变差具有相同频率趋势；
- 改变房间环境后S11趋势基本不变。

### 11.2 天线互耦证据

满足以下组合时，优先判断多天线互耦：

- 某些相邻天线对S21明显比其他组合更接近0 dB；
- 495～510 MHz的耦合明显增强；
- 只有7TX1RX时SNR下降，1TX1RX时正常；
- 改变其他天线的50 Ω终接状态会影响被测天线S11；
- 异常随天线位置/间距变化，而不是跟随某个射频模块。

S21没有统一合格门限。可用下表作问题严重程度参考，但不能代替系统校准预算：

| 天线间S21 | 参考判断 |
|---:|---|
| 高于-10 dB | 耦合很强，优先处理 |
| -10～-15 dB | 耦合较强，可能明显影响多天线校准 |
| -15～-20 dB | 需要结合相位和ACM结果评估 |
| 低于-20 dB | 通常较弱，但七路叠加仍需系统验证 |
| 低于-30 dB | 单对耦合较低 |

“高于-10 dB”指更接近0 dB，例如-6 dB；“低于-20 dB”指更负，例如-25 dB。

### 11.3 空间多径证据

1. 保存整机安装状态的S21曲线；
2. 将整机平移约15 cm，保持所有天线相对位置不变；
3. 重新测同一天线对；
4. 或在主要反射方向放置吸波材料后复测；
5. 比较幅度凹点和相位曲线。

如果凹点频率或深度明显变化，环境多径占比较大。如果曲线基本不变，更偏向固定的阵内互耦。
环境对比改变后应视为新的测试状态，不能与原状态混为同一组数据。

## 12. 测量顺序建议

按以下顺序执行可以减少返工：

1. 拍照并编号8根天线；
2. 按最终结构安装，全部与有源模块断开；
3. 配置E5062A并完成完整两端口校准；
4. 用THRU和LOAD检查校准；
5. 测8根天线安装状态S11；
6. 测28组S21幅度；

## 14. 注意事项

- VNA测试线本身可能成为天线的一部分，必须固定走线；
- 其余端口开路、短路和50 Ω终接会产生不同结果，正式测试必须统一为50 Ω；
- 不要只看495 MHz一个点，必须保存470～510 MHz完整曲线；
- 不要只测相邻天线，远距离天线也可能因结构和方向图产生强耦合；
- S11较好但S21异常，说明端口匹配和阵间隔离是两个独立问题；
- S21较低不代表7路同时工作一定正常，最终仍需做真实7TX1RX校准SNR验证；
- 不要根据单次曲线立即调整天线长度或PA匹配元件，应先完成重复测试和环境对比；
- 如果校准件型号、软键名称或接头规格无法确认，应停止正式测试并查阅对应手册。
