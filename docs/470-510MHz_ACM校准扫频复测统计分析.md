本轮最重要的结论：

1. **470–499 MHz是目前两轮测试共同确认的稳定频段**，60个频点样本全部为100/100。
2. 500–502 MHz本轮为100/100，其中501、502 MHz两轮均为100/100；500 MHz首轮为
   99/100、本轮为100/100，说明500 MHz附近已经接近边界，但没有形成持续失败。
3. **503 MHz以上存在明确问题**。本轮503–505 MHz均为0/100，506–510 MHz虽然恢复出
   一部分有效结果，但没有一个频点达到100次。
4. 503–510 MHz两轮逐频点有效次数差异很大，平均绝对差为45.88次，相关系数约
   `-0.285`。因此高频端问题具有明显随机性或状态相关性，不能解释为一个固定、单调的
   高频截止点。
5. 本轮CH1–CH7平均复方差从470–499 MHz的`9.0957e-4`升高到500–502 MHz的
   `1.5523e-3`，再升高到504–510 MHz有效样本的`2.5018e-3`。高频有效样本的方差约为
   低频段的2.75倍，但503–505 MHz没有有效因子，无法用因子方差描述失败样本。

## 3. 结果分析

### 3.1 高频端不是简单的单调衰减

若问题只是随频率升高而单调恶化，预计有效次数会随频率连续下降。但本轮实际结果为：

```text
503  504  505  506  507  508  509  510 MHz
  0    0    0   82   40   16    5   62 次
```

506 MHz和510 MHz存在明显恢复，且相同频点与首轮差异很大。这更符合下列一种或多种情况：

- 天线阵列通道间耦合形成频率相关深衰落，安装环境或周边反射变化会改变深衰落位置；
- 自动增益获取结果在临界SNR附近存在随机收敛差异；
- 某个数据通道、ACM通道或特定tone在不同启动时成为最差链路；
- 射频开关、PA/LNA工作状态或多通道同时收发产生状态相关干扰。

仅凭两轮总有效次数还不能区分上述原因，但可以排除“整个470–510 MHz范围普遍不稳定”。

### 3.2 因子方差仍然支持高频链路不稳定

本轮有因子可统计的504–510 MHz频点中，CH7具有最大的绝对方差：CH7平均复方差约
`7.3517e-3`，而470–499 MHz为`1.8560e-3`，约上升3.96倍。CH5、CH3和CH1也有明显
升高。因此高频端不仅有效次数下降，成功产生的因子本身也比低频端更分散。

需要注意：503–505 MHz为0次，失败数据没有写入因子文件；高频方差仅代表“幸存的有效
样本”，不能反映全部100次尝试。

### 3.3 两轮共同结论

| 判断 | 证据强度 | 说明 |
|---|---|---|
| 470–499 MHz稳定 | 高 | 两轮共60个频点结果全部100/100 |
| 500 MHz处于边界附近 | 中 | 两轮分别99/100、100/100 |
| 501–502 MHz当前可用 | 中 | 两轮均100/100，但因子方差高于低频段 |
| 503–510 MHz不稳定 | 高 | 两轮均至少出现一次未达到100次，且本轮全部失败 |
| 高频问题是固定单调截止 | 低/不支持 | 两轮高频点间恢复位置和有效次数差异很大 |

## 6. 下一步建议

优先在503、505、506、507、510 MHz各连续重复5次，同时记录每次自动增益结果，以及15个
tone在各数据通道和两个ACM通道上的SNR。应按“频率×重复次数×通道×tone”统计失败率，
而不是只看一次启动的总有效次数。这样才能确认深衰落是否固定在某个频率，还是增益搜索或
特定通道的随机收敛问题。
