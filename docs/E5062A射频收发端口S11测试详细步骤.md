# Agilent E5062A 射频发送与接收端口 S11 测试详细步骤

## 1. 文档目的

本文面向第一次使用网络分析仪的操作人员，说明如何使用照片中的 **Agilent E5062A
ENA Series Network Analyzer（300 kHz～3 GHz）**，测试射频板发送端口（TX）和接收端口
（RX）在 **470 MHz～510 MHz** 范围内的 S11、回波损耗和驻波比。

本文测试的是端口阻抗匹配，不是发射功率、频谱或接收灵敏度：

- **S11** 表示从被测端口反射回来的信号比例；
- S11 越负，匹配通常越好；
- 回波损耗 `Return Loss = -S11(dB)`，数值越大越好；
- 常用参考：S11 ≤ -10 dB，等价于回波损耗 ≥ 10 dB、VSWR ≤ 1.92；
- 项目最终合格门限应以射频原理图、模块规格书或项目指标为准，不能只凭上述通用参考判定。

> **最重要的安全规则：E5062A 是网络分析仪，不是功率计。严禁在射频板正在发射
> 载波、Tone、BCN 或数据时，把 TX 端直接接到 E5062A。** 本项目既有配置可能产生约
> 24 dBm 的发射功率，直接送入测试端口有损坏仪器的风险。本文默认 DUT 不主动发射，
> E5062A 只输出很小的扫频测试信号。

## 2. 先确认“TX S11”和“RX S11”的含义

同一个天线口经射频开关连接到 PA（发送链路）或 LNA（接收链路）时，TX S11 和 RX S11
必须分别在对应开关状态下测试：

| 测试项 | DUT 状态 | 被测对象 |
|---|---|---|
| TX S11 | 射频开关置于 TX，但 PA 不产生任何射频输出 | 天线口向发送匹配网络/PA 方向看到的阻抗 |
| RX S11 | 射频开关置于 RX，无外部信号源，DUT 不发射 | 天线口向接收匹配网络/LNA 方向看到的阻抗 |

如果板上有独立的 `TX OUT` 和 `RX IN` 接口，可以直接分别测试。如果板上只有一个
`ANT` 接口，必须由板卡控制程序将收发开关固定到 TX 或 RX 状态。仅仅修改文档中的端口
名称不能代替实际硬件状态切换。

优先采用以下两种方式：

1. **无源/断电测试**：适用于独立 TX、RX 接口，或断电时开关状态已明确的板卡；
2. **上电静态测试**：仅在必须上电才能固定收发开关时使用。上电后必须关闭 TX Tone、
   BCN、业务发送和周期发送，并先用频谱仪或功率计确认端口没有主动输出。E5062A 测试
   端口的最大允许射频输入为 **+10 dBm**；该值是不得触碰的仪器上限，不是建议测试值。
   本文规定：接入 E5062A 前，在最终校准面处测得的 DUT 任意主动输出必须 **≤ 0 dBm**，
   以保留至少 10 dB 安全余量；大于 0 dBm 时禁止直连，应先彻底关闭发射或使用额定功率、
   频率范围和衰减量均合适的保护衰减器。测试端口还不得带直流电压。

## 3. 所需物品

| 物品 | 数量 | 要求 |
|---|---:|---|
| Agilent E5062A | 1 台 | 照片所示 300 kHz～3 GHz 型号 |
| 50 Ω 射频测试线 | 1 根 | 接头与仪器、DUT 匹配，470～510 MHz 性能正常 |
| 一端口校准件 | 1 套 | OPEN（开路）、SHORT（短路）、LOAD（50 Ω 负载） |
| 转接头 | 按需 | 校准面与 DUT 接口一致，尽量少用 |
| 扭力扳手 | 1 把 | 按接头厂家规定扭矩使用；不确定时不要用钳子硬拧 |
| 直流隔离器（DC Block） | 建议 1 个 | DUT 端口可能带直流偏置时必须使用，且需包含在校准链路中 |
| 防静电腕带 | 1 套 | 测试 LNA、PA 等敏感器件时使用 |

校准件必须与仪器端口阻抗一致，通常为 50 Ω。若 OPEN/SHORT/LOAD 没有清晰标识，停止
操作，不要靠外观猜测。

## 4. 接线原则和校准面

推荐连接：

```text
E5062A PORT 1 ── 测试线 ──（必要时 DC Block）── 校准面 / DUT 射频口
```

OPEN、SHORT、LOAD 校准件和 DUT 都连接在最右侧同一个位置。该位置称为“校准面”。
校准完成后不能更换测试线、增加转接头、增加 DC Block 或改变连接顺序，否则必须重做校准。

本测试只使用 **PORT 1**。PORT 2 保持空闲，不要把 DUT 的另一个端口随意接到 PORT 2。
若未使用的 DUT 端口在产品工作时有规定终端，应按原理图/规格书接 50 Ω 负载。

## 5. 开机前安全检查

逐项确认并打勾：

- [ ] DUT 当前不会发送 Tone、载波、BCN、广播或业务数据；
- [ ] 不使用 `Test8710RFTest.exe` 的 TX Tone/发送功率测试模式；
- [ ] DUT 端口没有直流电压；若可能带偏置，已串联合适的 DC Block；
- [ ] 测试线和转接头为 50 Ω，接头中心针没有弯曲、后缩或异物；
- [ ] 测试线未接 DUT，先完成仪器设置和校准；
- [ ] 操作者佩戴防静电腕带；
- [ ] 不把信号源、功放输出或天线收到的强信号接入仪器。

若无法确认 DUT 是否主动输出，先不要连接 E5062A。先用额定功率足够的衰减器配合频谱仪
或功率计确认，输出消失后再进行 S11 测试。

## 6. 仪器开机与恢复初始状态

1. 确认 PORT 1 和 PORT 2 都没有连接主动射频源。
2. 打开 E5062A 电源，等待系统完全启动并出现测量画面。
3. 按前面板 **Preset** 键。如果屏幕出现确认菜单，按屏幕右侧软键 **OK** 或
   **Preset** 确认。
4. 等待曲线重新扫描。
5. 按前面板 **Channel Max**，让当前通道占满屏幕，便于观察。

说明：屏幕右边会随硬键变化显示一列“软键”。本文写成“按 **Cal** → **Calibrate**”时，
含义是先按前面板实体 **Cal** 键，再按屏幕右侧与 `Calibrate` 对齐的软键。不同固件的
英文可能略有差异，但应选择同义菜单，不要选择不认识的校准类型。

## 7. 设置 S11、频率范围和测试功率

### 7.1 选择 S11

1. 按前面板 **Meas**。
2. 按右侧软键 **S11**。
3. 按前面板 **Format**。
4. 按右侧软键 **Log Mag**。
5. 查看屏幕左上角，确认当前测量参数包含 `S11`，格式包含 `Log Mag` 或单位为 `dB`。

如果按 **Meas** 后看不到 S11，先按 **Trace Next** 选择当前曲线，再重复以上操作。

### 7.2 设置 470 MHz～510 MHz

1. 按前面板 **Start**。
2. 用数字键输入 `470`。
3. 按数字键区旁的单位软键 **M/µ** 或屏幕软键 **MHz**。屏幕底部应显示
   `START 470 MHz`。
4. 按前面板 **Stop**。
5. 输入 `510`，再按 **M/µ** 或 **MHz**。屏幕底部应显示 `STOP 510 MHz`。

也可以用等价设置：按 **Center** → `490` → **MHz**，再按 **Span** → `40` →
**MHz**。第一次使用时建议用 Start/Stop，比较不容易输错。

> 输入后必须检查单位。`470 Hz`、`470 kHz` 和 `470 MHz` 完全不同。

### 7.3 设置扫描点数

1. 按前面板 **Sweep Setup**（部分面板可能显示为 **Sweep Setup/Trigger**）。
2. 按软键 **Points**。
3. 输入 `401`，按 **Enter**。

401 点对应约 100 kHz 的频率间隔，适合查看整个 40 MHz 工作带宽。若菜单中没有 Points，
按 **Back** 返回上一层，或在 **Sweep Setup** 菜单中翻页查找。

### 7.4 设置仪器输出功率

1. 按前面板 **Power**。
2. 按软键 **Power** 或 **Level**。
3. 输入 `-20`，按单位 **dBm** 或 **Enter**。
4. 确认屏幕显示测试功率为 `-20 dBm`。

`-20 dBm` 是本文的保守起始值。若曲线噪声较大，可在确认 DUT 无主动输出且器件可承受的
前提下逐步提高到 `-10 dBm`；不要直接使用高功率。对上电 RX 链路，不应盲目提高功率，
以免使 LNA 或接收机进入压缩。

### 7.5 设置显示刻度（推荐）

1. 按 **Scale**。
2. 按软键 **Scale/Div**，输入 `5`，按 **Enter**，设置为 5 dB/格。
3. 按软键 **Reference Position**，输入 `8`，按 **Enter**。
4. 按软键 **Reference Value**，输入 `0`，按 **Enter**。

若固件菜单名称不同，也可以按 **Scale** → **Auto Scale**，然后确认纵轴能看到 0 dB 到
约 -40 dB。Auto Scale 只改变显示，不改变测量值。

## 8. 执行 PORT 1 一端口校准（OPEN/SHORT/LOAD）

校准必须在 470～510 MHz、当前功率、当前测试线和当前转接结构下完成。

### 8.1 进入校准菜单

1. 保持测试线连接 PORT 1，测试线末端暂不接 DUT。
2. 按前面板 **Cal**。
3. 按软键 **Calibrate**。
4. 按软键 **1-Port Cal** 或 **1-Port**。
5. 若仪器要求选择端口，按 **Port 1**。

### 8.2 OPEN 开路校准

1. 将标有 **OPEN** 的校准件轻轻旋到测试线末端。
2. 先用手对正螺纹，确认没有歪斜后再拧紧；需要扭力扳手时按校准件厂家要求操作。
3. 不要握住或晃动校准件，等屏幕曲线稳定。
4. 按右侧软键 **Open**。
5. 等待该软键旁出现勾、下划线变化或已测量提示。
6. 固定测试线前端，旋下 OPEN；不要用拧测试线的方式拆接头。

### 8.3 SHORT 短路校准

1. 接上标有 **SHORT** 的校准件。
2. 等曲线稳定，按软键 **Short**。
3. 等待已测量提示，然后旋下 SHORT。

### 8.4 LOAD 负载校准

1. 接上标有 **LOAD** 或 **50 Ω** 的校准件。
2. 等曲线稳定，按软键 **Load**。
3. 等待已测量提示。
4. 按软键 **Done**、**Done 1-Port Cal** 或 **Return** 完成校准。
5. 返回测量画面后，确认屏幕状态栏显示校准/误差修正已开启，例如 `Cor`、`C` 或
   `Correction On`。若显示 `Cor Off`，按 **Cal** → **Correction** → **On**。

> OPEN、SHORT、LOAD 的测量顺序通常可以改变，但三个标准必须全部完成。不要把 50 Ω
> 普通终端当作精密 LOAD，除非其规格覆盖 470～510 MHz 且已确认适用于校准。

## 9. 校准后快速检查

1. 校准完成后仍接着 LOAD，观察 470～510 MHz 曲线。
2. 精密 LOAD 的 S11 应明显低于 -10 dB，通常会比被测件好很多；如果曲线接近 0 dB，
   很可能是校准失败、接头松动或选错参数。
3. 轻轻移动测试线中段，曲线不应大幅跳动。若跳动明显，检查线缆和接头并重新校准。
4. 拆下 LOAD。此后不要改变测试线走向，不要触碰接头中心针。

该检查只能发现明显问题，不替代校准件的计量溯源或仪器性能验证。

## 10. 测试 TX 端口 S11

### 10.1 准备 TX 状态

1. 断开 DUT 电源。
2. 确认 DUT 端口名称：独立接口应为 `TX OUT`；共用接口应为 `ANT`。
3. 若断电状态不能形成真实 TX 通路，按板卡控制说明上电并将射频开关固定为 TX。
4. **确保 PA 没有激励**：关闭 TX Tone、BCN、广播、业务发送和自动重发。
5. 上电测试时，先在不连接 E5062A 的情况下确认端口没有主动射频输出。

### 10.2 连接和读取

1. 保持 E5062A 校准修正开启。
2. 将校准面连接到 DUT 的 TX/ANT 端口，拧紧接头。
3. 等待 2～3 次完整扫描，直到曲线稳定。
4. 按前面板 **Marker**。
5. 按软键 **Marker 1** → **On**（若 Marker 1 已开启则跳过）。
6. 输入 `470` → **MHz**，记录 470 MHz 的 S11。
7. 按 **Marker**，选择 **Marker 2** → **On**，输入 `490` → **MHz**，记录 490 MHz。
8. 选择 **Marker 3** → **On**，输入 `510` → **MHz**，记录 510 MHz。
9. 查找全频段最差点：按 **Marker** → **Marker Search** → **Max**。S11 的“最大值”最接近
   0 dB，是匹配最差的位置，记录其频率和 S11。
10. 如需查找最佳匹配点，按 **Marker Search** → **Min**，记录频率和 S11。

如果 **Max/Min** 找不到，使用旋钮移动 Marker，沿曲线寻找最接近 0 dB 的最高点，并记录。
不要把最深的凹点误当成全频段最差值。

### 10.3 切换到 VSWR 复核（可选）

1. 先抄下 S11 结果或保存数据。
2. 按 **Format** → **SWR**。
3. 用 Marker 查看 470、490、510 MHz 以及最差点的 VSWR。
4. 完成后按 **Format** → **Log Mag** 回到 S11 dB 显示。

## 11. 测试 RX 端口 S11

1. 从 DUT 拆下测试线。若 DUT 已上电，先关闭电源或进入明确的安全待机状态再改接线。
2. 独立 RX 口连接 `RX IN`；共用 ANT 口则将射频开关固定为 RX 状态。
3. 确认 TX Tone、BCN、广播和业务发送全部关闭。
4. RX 端可能有 LNA 偏置。若端口存在直流，必须使用校准时已经包含的 DC Block；如果
   校准时未包含，加入 DC Block 后重做第 8 章校准。
5. 将校准面连接到 RX/ANT 端口。
6. 等待 2～3 次完整扫描。
7. 按第 10.2 节相同方法记录 470、490、510 MHz、全频段最差点和最佳点。
8. 如需 VSWR，按第 10.3 节复核。

TX 和 RX 状态切换本身可能改变阻抗。每次结果必须记录 DUT 是断电、TX 静态、RX 静态，
以及 PA/LNA/射频开关的使能状态。

## 12. 保存屏幕和测量数据

### 12.1 保存到 U 盘

1. 将 FAT/FAT32 格式 U 盘插入仪器 USB 接口，等待仪器识别。
2. 按前面板 **Save/Recall**。
3. 若要保存仪器状态，按软键 **Save State**；输入名称，例如
   `TX_S11_470_510`，再按 **Save**。
4. 若菜单提供 **Save Trace Data**、**Save Data** 或 **CSV**，选择该项，将文件保存为
   `TX_S11_板号_日期.csv` 或 `RX_S11_板号_日期.csv`。
5. 若要保存屏幕，按 **Save/Recall** → **Save Image**（有些固件位于 **Display** 或
   **System** 菜单），格式选 PNG/BMP，分别保存 TX 和 RX 画面。
6. 等待保存完成提示后再拔 U 盘。

不同固件的存储软键名称可能不同。找不到图片保存项时，至少保存仪器状态和 CSV，并用相机
拍下包含频率范围、S11 曲线、Marker 读数和校准状态的完整屏幕。

### 12.2 保存前必须在画面中确认

- 测量参数为 S11；
- 格式为 Log Mag，单位为 dB；
- Start = 470 MHz，Stop = 510 MHz；
- 校准修正为 On；
- Marker 显示最差点频率和 S11；
- 文件名能区分 TX/RX、板号、端口号和测试日期。

## 14. 常见问题和处理

| 现象 | 可能原因 | 处理方法 |
|---|---|---|
| 曲线接近 0 dB | 端口开路/短路、选错参数、校准未开启 | 检查接头，确认 S11 和 Correction On，重做校准 |
| 曲线大幅抖动 | 接头松、测试线损坏、DUT 状态变化 | 停止移动线缆，紧固接头，固定 DUT 状态 |
| LOAD 校验也很差 | 校准件选错、校准步骤漏项、校准面改变 | 确认 OPEN/SHORT/LOAD 标识并重新校准 |
| TX 和 RX 曲线完全一样 | 收发开关没有真正切换或测到的是同一个无源节点 | 查控制信号和原理图，记录开关电平后重测 |
| 上电后曲线异常或仪器报警 | DUT 主动输出、端口带直流或发生自激 | 立即断开 DUT，关闭 DUT 电源，检查输出和 DC 偏置 |
| 频率显示不对 | 输入单位错误 | 重新按 Start/Stop，并明确选择 MHz |
| Marker Min 很好但通信仍差 | 只看了最佳点，带内其他位置匹配差 | 使用 Marker Max 查全频段最差点 |
| 加入转接头后结果变化 | 转接头不在原校准面内 | 保持最终连接结构并重新校准 |

## 15. 测试结束

1. 保存 TX、RX 的 CSV、屏幕图片和仪器状态。
2. 若 DUT 上电，先关闭 DUT 射频功能和电源。
3. 固定测试线接头，旋下 DUT，不要扭转线缆。
4. 从 E5062A PORT 1 拆线时同样固定接头并规范操作。
5. 给仪器端口、测试线和校准件装防尘帽。
6. 退出 U 盘或确认保存完成后拔出。
7. 按实验室规定关闭 E5062A 电源。
