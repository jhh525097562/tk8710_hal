# 470-510 MHz ACM每频点重复三次统计分析（2026-08-17）

## 1. 结论摘要

本轮使用2026-08-17 14:29构建的RK3506 `TestTRMmain`，按照470 MHz到510 MHz升频顺序、1 MHz步进，每个频点连续运行3次，共完成123次初始化ACM校准测试。

|---|---:|

| 有效校准总数 | 12,247 |
| 总体有效率 | 99.569% |
| 达到100/100的运行 | 113/123（91.87%） |
| 三次均达到100/100的频点 | 37/41（90.24%） |
| 出现未满额的频点 | 504、506、507、509 MHz |
| 三次均未满额的频点 | 506、507、509 MHz |
| 最低单次结果 | 509 MHz第3次：87/100 |

主要结论：

1. 470-503 MHz共102次运行全部达到100/100，低中频段稳定。
2. 504 MHz只有第2次为99/100；505、508、510 MHz三次均为100/100。
3. 506、507、509 MHz三次均未满额，属于本轮需要重点复核的频点。
4. 结果不是随频率单调恶化：508和510 MHz恢复为三次满额，说明不能仅用“高频端整体变差”解释。
5. CH7的因子波动显著高于其他数据通道，但高方差与有效次数不足并非一一对应，两个指标需要同时观察。

## 6. 校准因子方差辅助分析

因子解析采用18位有符号定点数并除以`2^15`。每个运行内按通道计算I/Q样本方差，复数方差定义为`Var(I)+Var(Q)`；CH0是固定参考`1+j0`。下表为123轮的通道聚合结果。

| 通道 | 平均幅度 | 平均复数方差 | 最大单轮方差 | 最大值位置 |
|---:|---:|---:|---:|---|
| CH0 | 1.000000 | 0.00000000 | 0.00000000 | 固定参考 |
| CH1 | 0.848948 | 0.00064241 | 0.00173606 | 499 MHz第1次 |
| CH2 | 1.109860 | 0.00079918 | 0.00203937 | 507 MHz第2次 |
| CH3 | 0.826061 | 0.00263026 | 0.03234994 | 495 MHz第3次 |
| CH4 | 0.959490 | 0.00036636 | 0.00088634 | 499 MHz第1次 |
| CH5 | 0.969972 | 0.00088032 | 0.00230716 | 510 MHz第3次 |
| CH6 | 1.000511 | 0.00043979 | 0.00497129 | 506 MHz第3次 |
| CH7 | 1.501319 | 0.01193195 | 0.27136587 | 509 MHz第3次 |

观察：

1. CH7的平均复数方差约为CH3的4.5倍，并在509 MHz第3次出现明显峰值，应优先检查CH7对应的天线耦合、SNR、增益和校准因子。
2. 频点平均方差最高的是508 MHz（`2.42e-2`），但508 MHz三次均为100/100；510 MHz方差也高而三次满额。
3. 509 MHz第2次只有88/100，但保存的有效因子平均方差较低。由于未通过的校准不会进入有效因子集合，方差存在“只统计成功样本”的幸存者偏差。
4. 因此，有效次数用于判断校准成功率，因子方差用于判断成功样本的稳定性；二者不能相互替代。

## 7. 与2026-08-12结果的对照

两轮二进制不同：8月12日SHA-256为`d4f7d577...38b1`，本轮为`9004639c...d96269`。测试日期、程序和可能的硬件环境均不同，下面仅作现象对照，不能直接归因于某项代码改动。

| 项目 | 2026-08-12 | 2026-08-17本轮 | 变化 |

| 总有效数 | 12293/12300 | 12247/12300 | -46 |
| 总有效率 | 99.943% | 99.569% | -0.374个百分点 |
| 100/100运行 | 120/123 | 113/123 | -7 |
| 三次均满额频点 | 38/41 | 37/41 | -1 |
| 500-510 MHz有效数 | 3293/3300 | 3247/3300 | -46 |

两轮470-499 MHz均全部满额，差异全部发生在500 MHz以上。异常频点位置也发生变化，说明需要使用同一二进制进行A/B测试，才能判断本次程序变化是否影响高频校准。

## 8. 建议的下一步验证

1. 固定当前`9004639c...d96269`二进制，对506、507、509 MHz各重复10次，保存每轮`gain.txt`和逐通道、逐tone SNR。
2. 在同一硬件状态下换回8月12日二进制，再对相同三个频点各重复10次，形成严格A/B对照。
3. 对CH7做重点隔离：交换CH7与稳定通道的天线/射频连接，判断异常跟随逻辑通道还是物理天线链路。
4. 分别执行470到510 MHz升频和510到470 MHz降频扫频，排除固定顺序、温度和前次校准状态的影响。
5. 工程验收仍建议每频点连续3次均达到100/100；按此标准，本轮504、506、507、509 MHz不通过。
