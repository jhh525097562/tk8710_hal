# MATLAB / C_model 对比图自动生成约定

用户要求：后续每次数据比对都要生成8根天线I/Q对比图。该要求已接入对比工作流，并记录在项目文档中。

## 每次自动输出

共享绘图函数：[tx_comparison_plots.py](tx_comparison_plots.py)。数据比对完成后，不论数值是否一致，均生成：

1. `all_antennas_full.png`：完整一帧8天线总图，每行一根天线，左I、右Q。
2. `all_antennas_zoom.png`：相同采样窗口的8天线局部放大图。
3. `antenna_01.png`～`antenna_08.png`：每根天线独立一张图，包含完整I/Q、局部I/Q、绝对误差和包络。
4. `图像索引.md`：图片链接、数据说明及各天线误差。
5. `plots.json`：模式、源文件路径/哈希、缩放系数、采样率、长度、放大范围和绘图脚本哈希。

蓝色实线为MATLAB，橙色虚线为C_model。使用当前运行的实际模式标签及固定输出缩放；不做时延、增益、相位拟合。放大窗口自动选择各天线按参考RMS归一后误差最大的位置，用于观察明显差异，不代表整帧。

全部原始采样保留用于绘图。完整图可能较密集，应结合局部图查看；不通过抽点隐藏异常。误差分母使用整段复数能量，不使用瞬时I/Q。

若数据长度不同，完整图分别绘制各自所有点；误差只统计共同区间，并显式标注长度不同，不能以局部重合判为一致。零参考能量的相对L2显示N/A。文件缺失或非有限值会明确报错，不生成伪成功图。

## 已接入的脚本

| 工作流 | 自动生成时机 |
|---|---|
| `run_matlab_compare.py` | 单帧RX/TX比对结束 |
| `run_multiuser_compare.py` | 多用户比对结束；图中标注双方各自RX用户数 |
| `run_imported_tx_compare.py` | 同源输入的每个控制版本分别输出 |
| `validate_adaptive_svd.py` | 当前fixed/float自适应SVD集成比对结束 |
| `probe_tx_svd_precision.py` | 每个SVD诊断版本比对后分别输出 |

每组图保存在对应运行目录新建的 `tx_plots_<时间戳>/`，结果JSON中自动记录 `plots` 字段，或每个版本的 `runs[版本].plots` 字段。生成图失败会使工作流明确报错；没有有效MATLAB参考的纯smoke不生成虚假的对照图。

后续新增对比工作流也应调用这个共享函数，并在交付说明中给出图像入口。这是项目约定，不只是本轮临时补图。

## 给历史结果补图

```powershell
Set-Location 'D:\CodexWorkSpace\K2301Cmodel\c_model'
python .\testbench_GWRX_TX\plot_tx_comparison.py --run .\validation\adaptive_svd_fixed_6_20260924_162930
```

多版本对照结果需指定 `--variant before_wrap` 或 `--variant after_wrap`。补图不改写历史数值结果JSON。

也可以明确指定文件，避免任何结果目录识别：

```powershell
python .\testbench_GWRX_TX\tx_comparison_plots.py --reference .\validation\multiuser_float_20260924_150540_506860\matlab\matlab_tx_8ant_baseband.txt --actual .\validation\adaptive_svd_fixed_6_20260924_162930\cmodel\GWTXModule\case95\tx_frame0.txt --output .\validation\adaptive_svd_fixed_6_20260924_162930 --mode fixed --context '同源104用户TX；SVD最多6轮'
```
