# Float TX 局部相位异常定位

日期：2026-09-24。范围：解释 float 波形中 753～759 等局部采样与 MATLAB 不一致的原因。**仅诊断；正式算法和主入口未修复。**

后续状态：用户已授权正式修复，现已在 float 上采样输入及插值中点恢复回绕；并导入全部 MATLAB TX 输入进行多用户对比。见 [正式修复与同源 TX 复测](../validation/imported_tx_float_20260924_152146_236522/同源TX输入与回绕修复对比.md)。本文以下保留修复前诊断证据。

## 1. 已确认原因

根因是 **float 分支丢失了定点赋值所隐含的相位回绕，使相位插值函数接收到超出其预期范围的相位值**。

相位以 π 为单位。`p` 与 `p+2k` 转成 `exp(jπp)` 时等价；但若插值函数只处理一次跨周期跳变，这些表示不能直接互换。float 模式中，有些相邻调制输出包含不同的多周期偏移，插值时走错相位路径。原有采样端点仍正确，插入的点出现局部偏差。

证据链：

1. MATLAB 重放同一保存帧，实际调用 `PHY2_1Tx()` 和网关 `upsampling_new()`，取得 3264 个调制相位及 26113 个上采样相位。
2. 从原 C++ dump 最后 3264 行取得真实调制输出。按模 2 归一后，与 MATLAB 调制相位的最大差异仅 `6.66e-15`；直接转单位复数的最大差异 `3.46e-14`。
3. 复现当前 C++ 插值和频移算法，与已保存 C++ 单用户波形最大差异 `4.58e-16`，证明追踪点及索引正确。
4. 错误插值预测出的全部 **280 个异常索引**，与实际波形异常索引逐一相同，为 40 个区间、每区间 7 点。
5. 只在独立 C++ 主入口副本中将调制输出归一到 `[-1,1)` 后再调用原上采样类，8 天线均不再有这 280 个大误差点；全帧 L2 误差降至 `0.2610%～0.2643%`。

## 2. 涉及的源码位置

| 位置（当前源码行号） | 行为 | 对本问题的作用 |
|---|---|---|
| `Cls_tx_mod.h:448`、`:451`、`:456` | 保存符号过渡相位，没有显式取模 | 调制数组保留多周期相位表示 |
| `Cls_tx_mod.h:231` | `fix_set(t_sigDPFSKtempArrTS_tmp,10,1,...,FXP_WRAP)` | 定点下有周期回绕配置 |
| `Cls_tx_mod.h:495` | `t_sigDPFSKtempArrTS_tmp = m_sigDPFSKtempArrTS[i][j]`，随后输出 | `T=double` 时普通赋值不再回绕 |
| `Lib_utility.h:46` | `fix_set(double,...)` 是空函数 | 配置 `FXP_WRAP` 对 double 不生效 |
| `Cls_tx_us_2_1.h:356`、`:618` | 输入 `m_fxp` 配置 `FXP_WRAP`，再写 `m_in_buffer` | 第二个原本可回绕的定点赋值点在 float 下同样失去回绕 |
| `Cls_tx_us_2_1.h:662` | `add(in_1,in_2)`，相邻差大于 1 时只补/减一次 2，再除以 2 | 接收相差多个周期的相位时，不能还原正确短路径中点 |
| `Cls_tx_us_2_1.h:699` 起 | 逐级 2× 插值，当前为 8× | 一个错误相位中点扩展为 7 个错误插值点 |
| `GWRXTX_testbench.cpp:809`、`:834` | `m_tx_mod.go()` → `m_tx_us.go()` | 异常在这两个模块交接后转成波形 |

MATLAB 对应实现：

- `1.2GWTxCode/PHY2_1GWTx/DpfskModulationTSNew.m` 的 `key==2` 分支，306～309 行输出使用 `mod(value+1,2)-1`。
- `1.2GWTxCode/PHY2_1GWTx/upsampling_new.m` 的 `add()` 在平均后还做 `out>1` 减 2、`out<-1` 加 2。

仅在 C++ `add()` 输出处补 MATLAB 的单次回绕、而继续输入未经归一的多周期相位，不足以正确解决问题；需要首先恢复输入相位的范围契约。本次确认的是该契约丢失造成异常，不建议仅按图对某几个点补偿。

## 3. 图中 753～759 点的数值解释

所有索引从 0 开始。TX 相位前缀为 48 点，上采样为 8 倍；原调制索引 46、47 对应包含前缀后的输入索引 94、95，最终端点为 752、760。

| 项目 | C_model 原 float | MATLAB |
|---|---:|---:|
| 第一个端点相位 / π | -1.375 | 0.625 |
| 第二个端点相位 / π | 2.8674174785275226 | 0.8674174785275226 |
| 数值相位差 / π | 4.242417478527523 | 0.2424174785275226 |

两个端点转成 I/Q 分别等价；但当前 C++ `add()` 得到的中点为：

```text
(-1.375 + 2.8674174785275226 - 2) / 2
= -0.2537912607362387
```

MATLAB 输入已经归一，中点为：

```text
(0.625 + 0.8674174785275226) / 2
= 0.7462087392637613
```

两者中点正好差 **1π，即 180°**，对应图中最明显的采样 756。经过三层插值，端点之间 753～759 的七个新采样都发生偏离，而到采样 760 又恢复，因而呈现“局部扭曲、两侧吻合”的形状。

| 输出采样索引 | 原 C++ 插值相位 / π | 输入归一后的插值相位 / π |
|---|---:|---:|
| 752 | -1.37500000 | 0.62500000 |
| 753 | -1.59469782 | 0.65530218 |
| 754 | -1.81439563 | 0.68560437 |
| 755 | -2.03409345 | 0.71590655 |
| 756 | -0.25379126 | 0.74620874 |
| 757 | 0.02651092 | 0.77651092 |
| 758 | 0.30681311 | 0.80681311 |
| 759 | 0.58711529 | 0.83711529 |
| 760 | 2.86741748 | 0.86741748 |

这不是接近零的 I/Q 分母问题，也不是 8 天线各自发生的不同问题：错误先发生在公共单用户信号，随后乘上各天线权重，故各天线异常位置相同。

## 4. 独立 C++ 对照实验

诊断脚本：[diagnose_tx_phase.py](diagnose_tx_phase.py)。MATLAB 参考阶段重放：[diagnose_tx_phase.m](diagnose_tx_phase.m)。

脚本在 `validation/tx_phase_diagnosis_20260924/` 创建独立主入口副本，继续包含项目的原算法头文件，仅在该副本 `m_tx_mod.go()` 之后插入：

```cpp
for (int k = 0; k < m_tx_mod.m_outlen; ++k) {
    out[k] -= 2.0 * std::floor((out[k] + 1.0) / 2.0);
}
```

这是用于证实原因的单变量诊断实验，不是已经合入主项目的修复。输入、参数、TX bit、RX 算法、权重、频移和其它算法保持相同。

| 天线 | 原 float 全帧 L2 | 诊断副本全帧 L2 | >1% RMS 的局部异常点（原→诊断） |
|---|---:|---:|---:|
| 1 | 15.5431% | 0.2630% | 280 → 0 |
| 2 | 15.5472% | 0.2618% | 280 → 0 |
| 3 | 15.5441% | 0.2617% | 280 → 0 |
| 4 | 15.5453% | 0.2610% | 280 → 0 |
| 5 | 15.5467% | 0.2614% | 280 → 0 |
| 6 | 15.5464% | 0.2612% | 280 → 0 |
| 7 | 15.5424% | 0.2643% | 280 → 0 |
| 8 | 15.5470% | 0.2616% | 280 → 0 |

1% RMS 是定位用阈值，不是最终验收标准。局部大误差消失不等于整个模型已逐 bit 一致。

独立重放插值、尚未引入频移和权重时，将 C++ 输入归一后的单位复数结果与 MATLAB 最大误差为 `2.09e-14`。剩余整帧约 0.26% 的误差已有另一个明确来源：

```text
C++ 频移相位步进 / π = 2 * Freq * 274878 / 2^35
MATLAB 相位步进 / π = 2 * Freq / 125000
```

当前 `Freq=-10025 Hz`，C++ 仍沿用硬件近似系数；到帧尾累计相位差约 `-0.0045200069 rad`，另叠加此前已测得的权重差异。这与局部 180° 异常是不同问题，本轮未修改这两项。
