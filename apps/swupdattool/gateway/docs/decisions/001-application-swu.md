# ADR-001：三应用事务升级与Web统一控制

状态：Accepted。日期：2026-09-15。

## 背景

原SWU示例仅移动UART测试程序，不能保证MQTT/Web/TK8710配套升级；守护会拉起被停止的程序，旧S99 stop又会杀掉发起升级的Web。目标SWUpdate还使用固定socket，不能与原8080更新后台并发运行。

## 决策

固定包内容为三个应用和JSON-C版本辅助工具。所有载荷先暂存并校验，再备份、暂停守护、停止业务、逐文件rename，最后提交版本。用持久化prepared/applying/committed状态和S98恢复处理未完成安装。

Web保持旧inode提供状态，成功后负责重启。S80不再启动原8080后台/自动重启监听器；Web按需调用目标CLI并拒绝冲突进程。TMPDIR只用于临时文件隔离。

## 取舍

不选择直接覆盖整个userdata，以保留现场配置/校准。当前不引入rootfs A/B，因为本次需求是应用升级且现有分区/引导机制未做A/B验收。不在preinst停止Web，避免升级控制者消失。

此方案需要一次基础固件更新；无物理断电、签名链或业务健康回滚保证。文件恢复测试和实际Web升级证据见上级验证报告。
