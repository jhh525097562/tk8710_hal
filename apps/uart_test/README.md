# RK3506g UART 921600 测试 Demo

本仓库提供一个在 RK3506g 平台上使用已实现的 UART 节点、波特率 921600 的测试应用示例，以及简单的测试脚本主体。应用基于 Linux 用户态串口 API 实现，使用 raw 模式、8N1、无或可选 RTS/CTS 流控。

## 组成
- uart_demo.c: UART 测试应用（C 语言实现）
- Makefile: 编译指令
- README.md: 使用说明
- test_plan.md: 测试计划（简要版本，后续可扩展）

## 编译
1. 确保主机具备编译器环境（gcc）。
2. 在仓库根目录执行：
```
make
```
此命令将生成可执行程序 `uart_demo`。

## 运行
请以 root 权限运行，设备节点请替换为实际的 UART 设备节点，例如 /dev/ttyS1。
```
sudo ./uart_demo /dev/ttyS1 921600 [-v] [-f]
```
- -v: 启用接收数据输出和详细日志
- -f: 启用硬件流控 RTS/CTS

示例：
```
sudo ./uart_demo /dev/ttyS1 921600 -v
```

## 目标与注意事项
- 921600bps 在一些平台的 UART 控制器可能不支持，若遇到不支持时请更换到平台支持的最高速率，或检查内核驱动/设备树配置。
- 如需开启流控，请在正确引脚上接 RTS/CTS，并在命令行加上 -f。
- 测试数据流量对 CPU 负载有一定影响，长时间持续传输时请关注系统温度及资源占用。
