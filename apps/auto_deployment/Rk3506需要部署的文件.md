## tdaemon 当前守护命令

`tk8710_gw` 预置在 `/userdata`，因此 `/etc/tdaemon.conf` 使用：

```ini
proc=/userdata/tk8710_gw -w /userdata/ -g 0x2e --driver-log-level warn --trm-log-level warn
```

最新版程序来源、备份、镜像制作和验证步骤参见 [制作最新版App升级包.md](./制作最新版App升级包.md)。

#  其它注意事项

| 1、目前的板子的电池检测的IO和一键复位的IO是没有固定电平的，需要外部做上拉的电阻，不然有可能导致异常的电平的设备重启 |
| ------------------------------------------------------------ |
| 2、注意oem区存储的东西。                                     |
| 3、注意测试整个集成，包含web的升级。                         |
| 4、注意两个wifi的配置文件需要处理。                          |
| 5、产测文件要单独写MAC，SN、IP、wifi、version向各个文件写，默认密码修改为tlg20260509 |
| 6、脚本运行要删除set -x，避免过多日志的产生。                |
